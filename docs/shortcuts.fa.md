در هر جای تقویم <kbd>?</kbd> را بزنید تا فهرست میانبرها باز شود. این فهرست همیشه با نسخه‌ای که اجرا می‌کنید مطابق است. کلیدها از قراردادهای تقویم‌های وب مثل Google Calendar، Notion Calendar و Proton Calendar پیروی می‌کنند، بنابراین آنچه از قبل می‌دانید به کار می‌آید.

## نماها

| عمل | کلیدها |
| --- | --- |
| نمای هفته | <kbd>W</kbd> |
| نمای ماه | <kbd>M</kbd> |
| نمای سال | <kbd>Y</kbd> |
| نمای خط زمانی | <kbd>L</kbd> |
| نمای جدول | <kbd>S</kbd> |

## پیمایش

| عمل | کلیدها |
| --- | --- |
| رفتن به امروز | <kbd>T</kbd> |
| یک هفته / ماه / سال جلو | <kbd>→</kbd> |
| یک هفته / ماه / سال عقب | <kbd>←</kbd> |
| رفتن به یک تاریخ مشخص | <kbd>G</kbd> |

## موارد

| عمل | کلیدها |
| --- | --- |
| ایجاد یک مورد | <kbd>C</kbd> |
| حذف مورد بازشده | <kbd>Delete</kbd> یا <kbd>Backspace</kbd> |
| فقط حذف این مورد از یک سری | <kbd>Ctrl</kbd> <kbd>Delete</kbd> |
| جابه‌جایی یا تغییر اندازه فقط برای این مورد از یک سری | هنگام رها کردن <kbd>Ctrl</kbd> را نگه دارید |
| ایجاد نسخه مشابه از یک مورد | هنگام رها کردن <kbd>Alt</kbd> را نگه دارید |
| انتخاب وضعیت کار | <kbd>Alt</kbd> + کلیک روی چک‌باکس، یا راست‌کلیک روی آن |
| بزرگ‌نمایی نما | <kbd>Ctrl</kbd> + پیمایش |

## عمومی

| عمل | کلیدها |
| --- | --- |
| جستجوی موارد یا اجرای یک دستور | <kbd>/</kbd> یا <kbd>Ctrl</kbd> <kbd>P</kbd> یا <kbd>Ctrl</kbd> <kbd>K</kbd> |
| کلیدهای میانبر | <kbd>?</kbd> |
| [تنظیمات](settings.md) | <kbd>Ctrl</kbd> <kbd>,</kbd> |
| [نمایش فقط یک تقویم](calendars.md#show-only-one-calendar) یا بازگرداندن بقیه | <kbd>Alt</kbd> + کلیک روی چشم آن در نوار کناری |
| بستن یا بازگشت | <kbd>Esc</kbd> |

> [!NOTE]
> در مک، <kbd>Ctrl</kbd> در همه جا به‌صورت <kbd>⌘</kbd> و <kbd>Alt</kbd> به‌صورت <kbd>⌥</kbd> خوانده می‌شود، و <kbd>⌫</kbd> جای <kbd>Delete</kbd> را می‌گیرد (<kbd>Backspace</kbd> هم در همه جا حذف می‌کند).

میانبرهای تک‌حرفی هرگز هنگام تایپ در یک فیلد متنی کار نمی‌کنند.

## پالت دستورات

<kbd>/</kbd>، <kbd>Ctrl</kbd> + <kbd>K</kbd> یا <kbd>Ctrl</kbd> + <kbd>P</kbd> را بزنید تا موارد خود را جستجو کنید یا یک دستور اجرا کنید؛ هر سه یک کار را می‌کنند. جستجو در عنوان‌ها، توضیحات و مکان‌های همهٔ تقویم‌های شما می‌گردد، نه فقط روزهای روی صفحه، و یک مورد تکرارشونده را یک بار فهرست می‌کند. انتخاب یک مورد به تاریخ آن می‌رود و آن را باز می‌کند. دستورات نماها، پیمایش، موارد جدید، تقویم‌ها و تنظیمات شما را پوشش می‌دهند، و هرکدام کلیدهایش را کنارش نشان می‌دهد، بنابراین می‌توانید آن‌ها را در حین کار یاد بگیرید.
