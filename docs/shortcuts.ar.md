اضغط <kbd>?</kbd> في أي مكان من التقويم لفتح قائمة الاختصارات. وهي تطابق دائمًا الإصدار الذي تشغّله. تتبع المفاتيح أعراف تقويمات الويب مثل تقويم Google وNotion Calendar وProton Calendar، فما تعرفه مسبقًا ينفعك هنا أيضًا.

## طرق العرض

| الإجراء | المفاتيح |
| --- | --- |
| عرض الأسبوع | <kbd>W</kbd> |
| عرض الشهر | <kbd>M</kbd> |
| عرض السنة | <kbd>Y</kbd> |
| عرض المخطط الزمني | <kbd>L</kbd> |
| عرض الجدول | <kbd>S</kbd> |

## التنقل

| الإجراء | المفاتيح |
| --- | --- |
| الانتقال إلى اليوم | <kbd>T</kbd> |
| التقدم أسبوعًا أو شهرًا أو سنة | <kbd>→</kbd> |
| الرجوع أسبوعًا أو شهرًا أو سنة | <kbd>←</kbd> |
| الانتقال إلى تاريخ محدد | <kbd>G</kbd> |

## العناصر

| الإجراء | المفاتيح |
| --- | --- |
| إنشاء عنصر | <kbd>C</kbd> |
| حذف العنصر المفتوح | <kbd>Delete</kbd> أو <kbd>Backspace</kbd> |
| حذف هذا العنصر فقط من السلسلة | <kbd>Ctrl</kbd> <kbd>Delete</kbd> |
| نقل هذا العنصر فقط من السلسلة أو تغيير حجمه | اضغط مع الاستمرار على <kbd>Ctrl</kbd> أثناء الإفلات |
| إنشاء نسخة من عنصر | اضغط مع الاستمرار على <kbd>Alt</kbd> أثناء الإفلات |
| اختيار حالة المهمة | <kbd>Alt</kbd> + نقر على مربع الاختيار، أو نقر بزر الماوس الأيمن عليه |
| تكبير العرض وتصغيره | <kbd>Ctrl</kbd> + تمرير |

## عام

| الإجراء | المفاتيح |
| --- | --- |
| البحث في العناصر أو تشغيل أمر | <kbd>/</kbd> أو <kbd>Ctrl</kbd> <kbd>P</kbd> أو <kbd>Ctrl</kbd> <kbd>K</kbd> |
| اختصارات لوحة المفاتيح | <kbd>?</kbd> |
| [الإعدادات](settings.md) | <kbd>Ctrl</kbd> <kbd>,</kbd> |
| [إظهار تقويم واحد فقط](calendars.md#show-only-one-calendar)، أو إعادة إظهار البقية | <kbd>Alt</kbd> + نقر على رمز العين الخاص به في الشريط الجانبي |
| الإغلاق أو الرجوع | <kbd>Esc</kbd> |

> [!NOTE]
> على أجهزة Mac، يقابل <kbd>Ctrl</kbd> المفتاحَ <kbd>⌘</kbd> ويقابل <kbd>Alt</kbd> المفتاحَ <kbd>⌥</kbd> في كل مكان، ويحل <kbd>⌫</kbd> محل <kbd>Delete</kbd> (ويحذف <kbd>Backspace</kbd> أيضًا في كل مكان).

لا تعمل الاختصارات المكونة من حرف واحد أبدًا أثناء الكتابة في حقل نصي.

## لوحة الأوامر

اضغط <kbd>/</kbd> أو <kbd>Ctrl</kbd> + <kbd>K</kbd> أو <kbd>Ctrl</kbd> + <kbd>P</kbd> للبحث في عناصرك أو تشغيل أمر؛ فالثلاثة تؤدي الشيء نفسه. يبحث البحث في العناوين والأوصاف والمواقع في كل تقويماتك، لا في الأيام المعروضة على الشاشة فقط، ويعرض العنصر المتكرر مرة واحدة. وتظهر عناصر التقويمات المخفية باهتة. واختيار عنصر ينقلك إلى تاريخه ويفتحه، ويعيد إظهار تقويمه إن كان مخفيًا. وتشمل الأوامر طرق العرض، والتنقل، والعناصر الجديدة، وتقويماتك، وإعداداتك، ويعرض كل أمر مفاتيحه بجانبه، فتتعلمها أثناء الاستخدام.
