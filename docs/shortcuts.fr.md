---
title: Raccourcis clavier
description: "Utilisez Mitra au clavier : vues, navigation, entrées et palette de commandes."
---

Appuyez sur <kbd>?</kbd> n'importe où dans le calendrier pour ouvrir la liste des raccourcis. Elle correspond toujours à la version que vous utilisez. Les touches suivent les conventions des calendriers web comme Google Calendar, Notion Calendar et Proton Calendar, si bien que ce que vous savez déjà s'applique.

## Vues

| Action | Touches |
| --- | --- |
| Vue semaine | <kbd>W</kbd> |
| Vue mois | <kbd>M</kbd> |
| Vue année | <kbd>Y</kbd> |
| Vue chronologie | <kbd>L</kbd> |
| Vue tableau | <kbd>S</kbd> |

## Navigation

| Action | Touches |
| --- | --- |
| Aller à aujourd'hui | <kbd>T</kbd> |
| Avancer d'une semaine / d'un mois / d'une année | <kbd>→</kbd> |
| Reculer d'une semaine / d'un mois / d'une année | <kbd>←</kbd> |
| Aller à une date précise | <kbd>G</kbd> |

## Entrées

| Action | Touches |
| --- | --- |
| Créer une entrée | <kbd>C</kbd> |
| Supprimer l'entrée ouverte | <kbd>Delete</kbd> ou <kbd>Backspace</kbd> |
| Supprimer uniquement cette entrée d'une série | <kbd>Ctrl</kbd> <kbd>Delete</kbd> |
| Déplacer ou redimensionner uniquement cette entrée d'une série | maintenez <kbd>Ctrl</kbd> en déposant |
| Dupliquer une entrée | maintenez <kbd>Alt</kbd> en déposant |
| Choisir le statut d'une tâche | <kbd>Alt</kbd> + clic sur la case à cocher, ou clic droit dessus |
| Zoomer la vue | <kbd>Ctrl</kbd> + défilement |

## Général

| Action | Touches |
| --- | --- |
| Rechercher des entrées ou exécuter une commande | <kbd>/</kbd> ou <kbd>Ctrl</kbd> <kbd>P</kbd> ou <kbd>Ctrl</kbd> <kbd>K</kbd> |
| Raccourcis clavier | <kbd>?</kbd> |
| [Paramètres](settings.md) | <kbd>Ctrl</kbd> <kbd>,</kbd> |
| [N'afficher qu'un calendrier](calendars.md#show-only-one-calendar), ou rétablir les autres | <kbd>Alt</kbd> + clic sur son œil dans la barre latérale |
| Fermer ou revenir en arrière | <kbd>Esc</kbd> |

> [!NOTE]
> Sur un Mac, <kbd>Ctrl</kbd> se lit <kbd>⌘</kbd> et <kbd>Alt</kbd> se lit <kbd>⌥</kbd> partout, et <kbd>⌫</kbd> remplace <kbd>Delete</kbd> (<kbd>Backspace</kbd> supprime aussi partout).

Les raccourcis à une seule lettre ne se déclenchent jamais pendant que vous écrivez dans un champ de texte.

## Palette de commandes

Appuyez sur <kbd>/</kbd>, <kbd>Ctrl</kbd> + <kbd>K</kbd> ou <kbd>Ctrl</kbd> + <kbd>P</kbd> pour rechercher vos entrées ou exécuter une commande ; les trois font la même chose. La recherche parcourt les titres, les descriptions et les lieux de tous vos calendriers, pas seulement les jours à l'écran, et liste une entrée récurrente une seule fois. Choisir une entrée va à sa date et l'ouvre. Les commandes couvrent les vues, la navigation, les nouvelles entrées, vos calendriers et vos paramètres, et chacune affiche ses touches à côté, pour que vous les appreniez au fur et à mesure.
