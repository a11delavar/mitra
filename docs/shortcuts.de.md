---
title: Tastenkürzel
description: "Bedien Mitra mit der Tastatur: Ansichten, Navigation, Einträge und die Befehlspalette."
---

Drück <kbd>?</kbd> irgendwo im Kalender, um die Liste der Tastenkürzel zu öffnen. Sie passt immer zur Version, die du nutzt. Die Tasten folgen den Konventionen von Web-Kalendern wie Google Calendar, Notion Calendar und Proton Calendar, sodass du Bekanntes weiterverwenden kannst.

## Ansichten

| Aktion | Tasten |
| --- | --- |
| Wochenansicht | <kbd>W</kbd> |
| Monatsansicht | <kbd>M</kbd> |
| Jahresansicht | <kbd>Y</kbd> |
| Zeitleistenansicht | <kbd>L</kbd> |
| Tabellenansicht | <kbd>S</kbd> |

## Navigation

| Aktion | Tasten |
| --- | --- |
| Zu heute springen | <kbd>T</kbd> |
| Eine Woche / einen Monat / ein Jahr vor | <kbd>→</kbd> |
| Eine Woche / einen Monat / ein Jahr zurück | <kbd>←</kbd> |
| Zu einem bestimmten Datum springen | <kbd>G</kbd> |

## Einträge

| Aktion | Tasten |
| --- | --- |
| Einen Eintrag erstellen | <kbd>C</kbd> |
| Den geöffneten Eintrag löschen | <kbd>Delete</kbd> oder <kbd>Backspace</kbd> |
| Nur diesen Eintrag einer Serie löschen | <kbd>Ctrl</kbd> <kbd>Delete</kbd> |
| Nur diesen Eintrag einer Serie verschieben oder in der Größe ändern | beim Ablegen <kbd>Ctrl</kbd> gedrückt halten |
| Einen Eintrag duplizieren | beim Ablegen <kbd>Alt</kbd> gedrückt halten |
| Einen Aufgabenstatus wählen | <kbd>Alt</kbd> + Klick auf das Kästchen oder Rechtsklick darauf |
| Die Ansicht zoomen | <kbd>Ctrl</kbd> + Scrollen |

## Allgemein

| Aktion | Tasten |
| --- | --- |
| Einträge suchen oder einen Befehl ausführen | <kbd>/</kbd> oder <kbd>Ctrl</kbd> <kbd>P</kbd> oder <kbd>Ctrl</kbd> <kbd>K</kbd> |
| Tastenkürzel | <kbd>?</kbd> |
| [Einstellungen](settings.md) | <kbd>Ctrl</kbd> <kbd>,</kbd> |
| [Nur einen Kalender anzeigen](calendars.md#show-only-one-calendar) oder die anderen zurückholen | <kbd>Alt</kbd> + Klick auf sein Auge in der Seitenleiste |
| Schließen oder zurückgehen | <kbd>Esc</kbd> |

> [!NOTE]
> Auf einem Mac gilt durchgehend <kbd>⌘</kbd> für <kbd>Ctrl</kbd> und <kbd>⌥</kbd> für <kbd>Alt</kbd>, und <kbd>⌫</kbd> steht für <kbd>Delete</kbd> (<kbd>Backspace</kbd> löscht überall ebenfalls).

Kürzel aus einzelnen Buchstaben lösen nie aus, während du in einem Textfeld tippst.

## Befehlspalette

Drück <kbd>/</kbd>, <kbd>Ctrl</kbd> + <kbd>K</kbd> oder <kbd>Ctrl</kbd> + <kbd>P</kbd>, um deine Einträge zu durchsuchen oder einen Befehl auszuführen; alle drei tun dasselbe. Die Suche durchsucht Titel, Beschreibungen und Orte in allen deinen Kalendern, nicht nur die Tage auf dem Bildschirm, und listet einen wiederkehrenden Eintrag einmal auf. Wenn du einen Eintrag wählst, springt Mitra zu seinem Datum und öffnet ihn. Die Befehle decken die Ansichten, die Navigation, neue Einträge, deine Kalender und deine Einstellungen ab, und jeder zeigt seine Tasten daneben, sodass du sie nebenbei lernst.
