日历文件（`.ics`）和订阅链接（`webcal://`）是网络上分发日程的常见方式：邮件附件里的会议邀请、预订页面上的“添加到日历”按钮、球队赛程的“订阅”链接，都是如此。安装 Mitra 之后，它就能打开这两种内容，你也可以把它设为电脑上处理它们的默认应用。

> [!NOTE]
> 要打开文件和链接，需要在电脑上用基于 Chromium 的浏览器（如 Chrome、Edge、Brave 或 Opera）把 Mitra [安装为应用](install-app.md)。不过在任何浏览器中，你都可以把 `.ics` 文件拖到 Mitra 上。

## 把 Mitra 设为默认应用

先安装 Mitra。第一次用日历文件或链接打开 Mitra 时，浏览器可能会询问是否允许 Mitra 处理它，请选择 **允许**。然后让系统用 Mitra 打开 `.ics` 文件。

在 Windows 上，在文件资源管理器中右键点击一个 `.ics` 文件，选择 **打开方式 → 选择其他应用**，选中 **Mitra**，再点 **始终**。之后也可以在 **设置 → 应用 → 默认应用** 中更改。

在 macOS 上，在访达中按住 Control 键点按一个 `.ics` 文件，选择 **显示简介**。在 **打开方式** 下选择 **Mitra**，然后点按 **全部更改…** 并确认。

在 Linux 上，在文件管理器中右键点击一个 `.ics` 文件，打开 **属性 → 打开方式**，选择 **Mitra** 并将其设为默认应用。

如果 Mitra 已经打开，你再打开的文件或链接会交给这个窗口处理，而不会另开一个窗口。

## 添加日历文件

用 Mitra 打开一个 `.ics` 文件，或者把它从桌面或文件管理器拖到 Mitra 上。拖放在普通的浏览器标签页中同样可用，无需安装任何东西。一次打开多个文件时，会逐个处理。

Mitra 会询问要把条目添加到哪个日历。在真正添加之前，它会先告诉你这个日历存不了哪些内容：哪些条目会被略过，哪些条目会丢失部分信息，比如目标日历不支持提醒时，提醒就会丢失。确认无误后，按下注明条目数量的按钮，例如 **添加 12 个条目**。想换一个日历，点箭头返回即可。文件本身始终不会被改动。

每个条目都会作为新副本添加，所以同一个文件添加两次，每个条目就会出现两次。日历中已有的内容不会被覆盖。

同一文件中条目之间的子任务和依赖关系，导入后仍会保持关联。重复条目中已删除的单次，导入后依然是删除状态。如果重复条目中有单独修改过的单次（比如某次会议被挪到了另一天），整个重复条目都会被略过，因为 Mitra 无法把重复条目和它的修改一起添加。

如果添加到一半失败，Mitra 会删除已经添加的条目，确保文件里的内容不会只导入一半。如果其中有些条目删不掉，Mitra 会告诉你还需要手动删除多少个。

## 通过 webcal 链接订阅

提供日历订阅的网站，比如体育赛程、学校学期安排或法定节假日，通常会链接到一个 `webcal://` 地址。点击这样的链接，Mitra 会打开 **日历订阅** 表单，并自动填好地址。检查一下地址，如果订阅源需要登录，就填写 **用户名（可选）** 和 **密码（可选）**，然后按 **连接**。接着打开这个日历，再按 **保存**。

点击链接本身并不会自动订阅：只有在你按下 **连接** 之后，Mitra 才会获取订阅源。

一个订阅就是一个只读日历，Mitra 会根据订阅源保持它的更新。具体原理请参阅[日历订阅](integrations/subscriptions.md)。
