Mitra의 모습은 평범한 CSS이고, 그 위에 직접 쓴 CSS를 더할 수 있습니다. 쓰지 않는 것은 숨기고, 오늘에 테두리를 두르고, 서버 전체에 원하는 색을 입혀 보세요. 쓸 곳은 두 군데입니다. 본인을 위한 **설정 → 일반 → 사용자 지정 CSS**, 그리고 로그인을 쓰는 서버라면 서버의 모든 사람을 위한 **설정 → 관리 → 모두를 위한 사용자 지정 CSS**입니다.

> [!WARNING]
> Mitra 1.0 전까지는 어떤 업데이트든 규칙이 겨냥하는 요소, 속성, 변수를 바꿀 수 있습니다. 오늘 동작하는 규칙이 업데이트 후에 동작하지 않거나, 무언가를 숨기기 시작할 수도 있습니다. 스타일시트는 짧게 유지하고, 업데이트한 뒤에는 Mitra를 한번 살펴보세요.

## 나만의 스타일시트

**설정 → 일반**을 열고 **사용자 지정 CSS** 아래 상자에 CSS를 입력하세요. 입력하는 동안 Mitra에 바로 적용되고, 입력을 멈추고 잠시 뒤에 저장되며, 로그인하는 모든 기기와 브라우저에서 계정을 따라다닙니다.

**사용자 지정 CSS** 옆의 스위치를 끄면 스타일시트를 잃지 않고 꺼 둘 수 있으며, [명령 팔레트](shortcuts.md)에서도 **사용자 지정 CSS: 끔**과 **사용자 지정 CSS: 켬**을 쓸 수 있습니다.

스타일시트를 저장하면 `@import`는 제거됩니다. 스타일시트를 링크하지 말고 전체를 붙여 넣으세요.

## 서버의 스타일시트

로그인을 쓰는 서버에서는 관리자가 서버의 모든 사람을 위해 Mitra의 모습을 바꿀 수 있습니다. **설정 → 관리**를 열고 **모두를 위한 사용자 지정 CSS** 아래 상자에 CSS를 입력하세요. 본인에게는 입력하는 동안 보이고, 다른 사람에게는 다음에 Mitra를 불러올 때부터 보입니다. 옆의 스위치를 끄면 내용을 잃지 않고 모두에게서 꺼 둘 수 있습니다. 서버에 처음 로그인한 사람이 그 서버의 관리자입니다. 로그인이 없으면 나만의 스타일시트가 이미 Mitra를 쓰는 모든 사람에게 적용되므로, 스타일시트는 그것 하나뿐입니다.

색, 글꼴, 서버가 이미 가진 [이름](configuration.md#name-your-instance)처럼 서버를 우리 것답게 만드는 것에 잘 어울립니다. 각자의 스타일시트는 그 뒤에 적용되므로, 둘이 같은 것을 정하면 각자의 스타일시트가 이깁니다.

## 내 규칙이 이깁니다

Mitra 자체 규칙은 `mitra`라는 캐스케이드 레이어 안에 있고 직접 쓴 규칙은 그렇지 않으므로, 선택자와 관계없이 직접 쓴 규칙이 Mitra의 규칙을 이깁니다. `!important`는 필요 없습니다. Mitra 자체의 몇 안 되는 `!important` 선언은 레이어가 반대 순서로 순위를 매기기 때문에 계속 위에 남습니다. 이 선언들이 레이아웃을 지탱합니다.

Mitra가 정한 것을 덧칠하지 않고 없애려면 해당 속성을 `revert`로 설정하세요. 다음은 월 보기에서 날짜 칸의 배경 면을 없앱니다.

```css
mitra-weeks mitra-day {
	background: revert;
}
```

## 예시

### 이번 달 밖의 날짜 숨기기

```css
mitra-weeks [data-outside] {
	visibility: hidden;
}
```

[월 보기](views/month.md)에서 표시 중인 달의 앞뒤 날짜를, 날짜 숫자와 배경까지 함께 숨깁니다. 그 날짜에 있는 항목은 남습니다. `visibility`는 그리드를 제자리에 두지만 `display: none`은 그리드를 무너뜨립니다. 확대하면 이번 달 날짜에 더 많은 공간이 생깁니다.

### 오늘에 테두리 두르기

```css
mitra-weeks mitra-day[today] {
	outline: 2px solid var(--color-accent);
	outline-offset: -2px;
}
```

`border` 대신 `outline`을 쓰는 이유는, 테두리를 쓰면 날짜 칸이 커져서 그리드가 밀리기 때문입니다.

### 나만의 색

```css
:root {
	--color-accent: light-dark(#2e7d32, #81c784);
	--border-radius: 8px;
}
```

`light-dark()`는 밝은 테마의 색을 먼저, 어두운 테마의 색을 다음에 받습니다. [설치된 앱](install-app.md)의 제목 표시줄을 포함해, Mitra가 이 변수들로 색을 칠하는 모든 곳이 따라 바뀝니다.

| 변수 | 칠하는 곳 |
| --- | --- |
| `--color-accent` | 오늘, 선택된 것, 포커스 링, 주요 버튼 |
| `--color-background-seed` | 모든 것 뒤의 바탕. 대화 상자의 바탕도 여기서 나옵니다 |
| `--color-surface` | 보기 안의 날짜 칸, 그리고 명령 팔레트처럼 바탕 위에 놓이는 것 |
| `--color-text` | 텍스트 |
| `--color-text-muted` | 힌트와 시각 같은 보조 텍스트 |
| `--color-error` | 오류와 경고 |
| `--border-radius` | 버튼, 항목, 대부분의 컨트롤의 모서리 |
| `--font-family` | 텍스트의 서체 |

## 겨냥할 대상 찾기

브라우저의 개발자 도구로 페이지에 무엇이 있는지 볼 수 있습니다. 무언가를 마우스 오른쪽 버튼으로 클릭하고 **검사**를 선택하세요. Mitra 자체 요소의 이름은 `mitra-…`입니다. 보기는 `mitra-days`(주), `mitra-weeks`(월), `mitra-months`(연), `mitra-timeline`, `mitra-table`이고, 날짜 칸은 `mitra-day`, 항목은 `mitra-entry-segment`, 사이드바는 `mitra-sidebar`입니다. 속성은 `today`, `data-outside`, `data-date`처럼 사실을 나타냅니다.

버튼, 입력란, 스위치, 메뉴 같은 컨트롤은 내부를 감춰 둡니다. `mitra-switch::part(switch)`처럼 파트를 통해, 그리고 컨트롤이 읽는 `--mitra-…` 변수를 통해 접근하세요. 더 깊이 접근해야 한다면 [이슈](https://github.com/a11delavar/mitra/issues)로 파트를 요청하세요.

## 건드리지 말아야 할 것

몇 가지는 Mitra를 지탱하고 있어서, 바꾸면 Mitra가 망가집니다.

- `mitra-day`나 보기 안의 `.entries`에 대한 `display` 또는 `position`: 이들은 보기 전체가 공유하는 그리드 위에 있으며, 그리드가 없으면 주 보기가 매우 느려집니다.
- `--_`로 시작하는 변수: 확대하는 동안 매 프레임 바뀌므로, 직접 설정하면 확대와 충돌합니다.
- 항목의 크기: 항목의 제목 부분은 너비에 따라 레이아웃을 고르므로, 바깥에서 크기를 정하면 레이아웃이 바뀔 수 있습니다.
- `all: unset`은 숨김도 해제하므로, 옆에 `[hidden] { display: none }`을 다시 적으세요.

## 규칙 때문에 되돌아갈 길이 가려졌을 때

`https://mitra.example.com/?css=off`처럼 주소에 `?css=off`를 붙이세요. 그러면 Mitra가 한 번 두 스타일시트 없이 불러와지므로, **설정**을 열고 스타일시트를 고칠 수 있습니다. 관리자도 같은 방법으로 모두를 위한 스타일시트를 고칩니다.

## 붙여 넣기 전에

스타일시트는 코드를 실행하지 않지만 주소를 불러올 수 있으며, 그런 목적으로 쓴 스타일시트는 화면에 있는 내용을 그 주소로 보낼 수 있습니다. 이해하는 CSS만 붙여 넣으세요. 나만의 스타일시트는 본인에게만 적용되지만, 서버의 스타일시트는 서버의 모든 사람에게 적용됩니다.

## 내 스타일시트 공유하기

상자 아래의 **GitHub에 공유**를 누르면 [Custom CSS](https://github.com/a11delavar/mitra/discussions/categories/custom-css) 카테고리에 스타일시트가 미리 담긴 새 토론이 열립니다. 무엇을 하는지 적고, 보여 줄 것이 있으면 스크린샷을 더해 게시하세요. 링크에 담기에 너무 긴 스타일시트는 대신 클립보드에 복사되므로 토론에 붙여 넣으면 됩니다. 이 카테고리에서 다른 사람들이 공유한 스타일시트도 찾을 수 있습니다. 붙여 넣기 전에 꼭 읽어 보세요.
