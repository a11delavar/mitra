---
title: Scorciatoie da tastiera
description: "Usa Mitra dalla tastiera: viste, navigazione, voci e tavolozza dei comandi."
---

Premi <kbd>?</kbd> in qualsiasi punto del calendario per aprire l'elenco delle scorciatoie. Corrisponde sempre alla versione che stai usando. I tasti seguono le convenzioni dei calendari web come Google Calendar, Notion Calendar e Proton Calendar, quindi ciò che già conosci vale anche qui.

## Viste

| Azione | Tasti |
| --- | --- |
| Vista settimanale | <kbd>W</kbd> |
| Vista mensile | <kbd>M</kbd> |
| Vista annuale | <kbd>Y</kbd> |
| Vista cronologia | <kbd>L</kbd> |
| Vista tabella | <kbd>S</kbd> |

## Navigazione

| Azione | Tasti |
| --- | --- |
| Vai a oggi | <kbd>T</kbd> |
| Avanti di una settimana / un mese / un anno | <kbd>→</kbd> |
| Indietro di una settimana / un mese / un anno | <kbd>←</kbd> |
| Vai a una data specifica | <kbd>G</kbd> |

## Voci

| Azione | Tasti |
| --- | --- |
| Crea una voce | <kbd>C</kbd> |
| Elimina la voce aperta | <kbd>Canc</kbd> o <kbd>Backspace</kbd> |
| Elimina solo questa voce di una serie | <kbd>Ctrl</kbd> <kbd>Canc</kbd> |
| Sposta o ridimensiona solo questa voce di una serie | tieni premuto <kbd>Ctrl</kbd> mentre rilasci |
| Duplica una voce | tieni premuto <kbd>Alt</kbd> mentre rilasci |
| Scegli lo stato di un'attività | <kbd>Alt</kbd> + clic sulla casella, oppure clic con il tasto destro |
| Ingrandisci la vista | <kbd>Ctrl</kbd> + scorrimento |

## Generale

| Azione | Tasti |
| --- | --- |
| Cerca voci o esegui un comando | <kbd>/</kbd> o <kbd>Ctrl</kbd> <kbd>P</kbd> o <kbd>Ctrl</kbd> <kbd>K</kbd> |
| Scorciatoie da tastiera | <kbd>?</kbd> |
| [Impostazioni](settings.md) | <kbd>Ctrl</kbd> <kbd>,</kbd> |
| [Mostra solo un calendario](calendars.md#show-only-one-calendar), o riporta gli altri | <kbd>Alt</kbd> + clic sul suo occhio nella barra laterale |
| Chiudi o torna indietro | <kbd>Esc</kbd> |

> [!NOTE]
> Su un Mac, <kbd>Ctrl</kbd> si legge come <kbd>⌘</kbd> e <kbd>Alt</kbd> come <kbd>⌥</kbd> ovunque, e <kbd>⌫</kbd> sostituisce <kbd>Canc</kbd> (<kbd>Backspace</kbd> elimina comunque ovunque).

Le scorciatoie a singola lettera non scattano mai mentre scrivi in un campo di testo.

## Tavolozza dei comandi

Premi <kbd>/</kbd>, <kbd>Ctrl</kbd> + <kbd>K</kbd> o <kbd>Ctrl</kbd> + <kbd>P</kbd> per cercare tra le tue voci o eseguire un comando; tutti e tre fanno la stessa cosa. La ricerca esamina titoli, descrizioni e luoghi di tutti i tuoi calendari, non solo i giorni sullo schermo, ed elenca una voce ricorrente una sola volta. Scegliere una voce porta alla sua data e la apre. I comandi coprono le viste, la navigazione, le nuove voci, i tuoi calendari e le tue impostazioni, e ognuno mostra accanto i propri tasti, così puoi impararli strada facendo.
