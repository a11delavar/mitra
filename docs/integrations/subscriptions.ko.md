---

많은 캘린더는 공유되는 대신 공개됩니다. 공휴일, 스포츠 경기 일정, 학기 일정, 회사에서 쓰는 도구의 피드, 또는 본인의 Google이나 Outlook 캘린더의 비공개 주소 같은 것들입니다. 이런 캘린더에는 로그인하지 않고 링크로 구독합니다.

**캘린더 구독**은 이런 링크 하나를 Mitra에 독립된 캘린더로 가져옵니다. 일정과, 작업이 있다면 작업도 함께 가져옵니다.

구독은 읽기 전용입니다. 피드는 변경을 받지 않는 다른 서버에 있으므로, Mitra는 피드가 공개한 내용을 보여 줄 뿐 다시 쓰지 않습니다. 그래도 캘린더 이름과 색상을 바꾸거나, 순서를 바꾸거나, 숨길 수는 있습니다. [읽기 전용 캘린더](../calendars.md#read-only-calendars)를 참고하세요. 편집할 수 있는 항목 사본을 두려면 캘린더의 **⋯** 메뉴에서 **다른 캘린더로 항목 복사…** 명령을 쓰세요.

## 캘린더 구독하기

1. 사이드바 아래쪽에서 **연동 추가**를 고른 다음 **캘린더 구독**을 고르세요.
2. **캘린더 URL**에 링크를 붙여 넣으세요. "구독" 버튼이 흔히 주는 `webcal://` 주소이거나, 보통 `.ics`로 끝나는 `https://` 주소입니다.
3. 피드가 요구하지 않는 한 **사용자 이름(선택)** 칸과 **비밀번호(선택)** 칸은 비워 두세요([비밀번호가 있는 피드](#feeds-with-a-password) 참고).
4. **연결**을 누르세요. Mitra가 피드를 읽고 캘린더를 나열합니다.
5. 캘린더를 켜 둔 채로 **저장**을 누르세요.

링크 하나가 캘린더 하나입니다. 여러 개를 구독하려면 링크마다 구독을 추가하세요.

캘린더 이름은 피드에서 가져오며, 피드에 색상이 있으면 색상도 가져옵니다. 사이드바에서 이름을 바꿀 수 있고, 바꾼 이름은 피드 자체에서 캘린더 이름을 바꿀 때까지 유지됩니다.

[Mitra를 기본 캘린더 앱으로 지정](../calendar-files.md)했다면, 웹 페이지에서 `webcal://` 링크를 클릭할 때 링크가 채워진 이 양식이 열립니다.

### 캘린더 링크 찾는 곳

| 제공 업체 | 찾는 곳 |
| --- | --- |
| Google 캘린더 | 캘린더 설정의 **캘린더 통합**(Integrate calendar) → **iCal 형식의 비공개 주소**(Secret address in iCal format) |
| Outlook 및 Microsoft 365 | **공유**(Share) → **캘린더 게시**(Publish a calendar)를 선택한 다음 ICS 링크 복사 |
| iCloud | 캘린더를 오른쪽 클릭 → **캘린더 공유**(Share Calendar) → **공개 캘린더**(Public Calendar) |
| Nextcloud | 캘린더의 **⋯** 메뉴 → **구독 링크 복사**(Copy subscription link) |
| 공개 캘린더 | 대부분의 공휴일, 스포츠, 학교 웹사이트에서 `.ics` 링크를 제공합니다 |

> [!CAUTION]
> 비공개 주소는 링크 모양을 한 비밀번호입니다. 주소를 가진 사람은 누구나 캘린더를 읽을 수 있습니다. 혼자만 알고 있고, 유출되었다면 제공 업체 설정에서 주소를 재설정하세요.

### 비밀번호가 있는 피드

대부분의 공개 피드는 링크 자체에 접근 키가 들어 있어 따로 필요한 것이 없습니다. 회사나 자체 호스팅 서버의 피드처럼 사용자 이름과 비밀번호(HTTP Basic 인증)를 요구하는 피드라면 구독할 때 입력하세요. Mitra는 비밀번호를 서버에 보관하고 브라우저로 다시 보내지 않습니다.

## 최신 상태 유지 방식

Mitra는 누가 Mitra를 열어 두었는지와 상관없이 구독마다 15분에 한 번 동기화하므로, Mitra를 연다고 피드를 더 빨리 가져오지는 않습니다([동기화 방식](README.md#how-syncing-works) 참고). 동기화는 부담이 적습니다. Mitra는 피드 서버에 바뀐 것이 있는지 묻고, 바뀐 경우에만 캘린더를 내려받습니다.

캘린더는 피드를 그대로 따릅니다. 피드에 추가된 항목은 Mitra에 나타나고, 피드에서 사라진 항목은 Mitra에서도 사라집니다.

캘린더가 이상해 보이면 캘린더의 **⋯** 메뉴에서 **항목 다시 가져오기**를 쓰세요. 피드를 처음부터 다시 읽습니다. 피드 자체는 건드리지 않습니다. [캘린더 다시 가져오기](../calendars.md#re-import-a-calendar)를 참고하세요.

## 문제 해결

- Mitra에 "The calendar requires a username and password"라고 나오면 보호된 피드입니다. 피드에 필요한 사용자 이름과 비밀번호를 입력하세요.
- Mitra에 "No calendar was found at that address"라고 나오면 링크에 오타가 없는지 확인하세요. 비공개 주소는 소유자가 재설정해도 더 이상 작동하지 않습니다.
- Mitra에 "The address did not return a calendar"라고 나오면 링크가 피드가 아닌 웹 페이지로 연결되는 것입니다. iCal, ICS 또는 구독이라고 표시된 링크를 찾으세요.
- Mitra에 "The calendar is too large to subscribe to"라고 나오면 피드가 20MB보다 커서 Mitra가 읽지 않는 것입니다.
