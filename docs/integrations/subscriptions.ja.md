多くのカレンダーは共有ではなく公開されています。祝日、スポーツの試合日程、学校の学期、職場のツールが出すフィード、自分の Google や Outlook カレンダーの非公開アドレスなどです。これらにはサインインせず、リンクで購読します。

**カレンダー購読**は、そうしたリンクを 1 つ、独立したカレンダーとして Mitra に取り込み、その予定と、あればタスクも表示します。

購読は読み取り専用です。フィードは変更を受け付けない別のサーバー上にあるため、Mitra は公開されている内容を表示するだけで、書き戻すことはありません。それでもカレンダーの名前変更、色の変更、並べ替え、非表示はできます。[読み取り専用カレンダー](../calendars.md#read-only-calendars)を参照してください。編集できるコピーとして項目を残したい場合は、**⋯** メニューの **項目のコピー先…** を使います。

## カレンダーを購読する

1. サイドバー下部の **連携を追加** を選び、**カレンダー購読** を選択します。
2. **カレンダー URL** にリンクを貼り付けます。「購読」ボタンがよく発行する `webcal://` アドレスか、多くの場合 `.ics` で終わる `https://` アドレスです。
3. **ユーザー名（任意）** と **パスワード（任意）** は、フィードが要求しない限り空のままにします（[パスワード付きフィード](#feeds-with-a-password)を参照）。
4. **接続** を押します。Mitra がフィードを読み取り、そのカレンダーを一覧表示します。
5. 有効なままにして **保存** を押します。

1 つのリンクにつき 1 つのカレンダーです。複数購読するには、それぞれに購読を追加します。

カレンダーはフィードから名前を引き継ぎ、フィードにあれば色も引き継ぎます。サイドバーで名前を変更でき、フィード側でカレンダー名が変わるまでは自分の付けた名前が使われます。

[Mitra を既定のカレンダーアプリにしている](../calendar-files.md)場合、Web ページ上の `webcal://` リンクをクリックすると、このフォームがリンクを入力済みの状態で開きます。

### カレンダーリンクの探し方

| 提供元 | 確認場所 |
| --- | --- |
| Google Calendar | カレンダーの設定で **Integrate calendar** → **Secret address in iCal format** |
| Outlook と Microsoft 365 | **Share** → **Publish a calendar** で ICS リンクをコピー |
| iCloud | カレンダーを右クリック → **Share Calendar** → **Public Calendar** |
| Nextcloud | カレンダーの **⋯** メニュー → **Copy subscription link** |
| 公開カレンダー | 祝日、スポーツ、学校関連のサイトの多くが `.ics` リンクを提供しています |

> [!CAUTION]
> シークレットアドレスはリンクの形をしたパスワードです。持っている人なら誰でもそのカレンダーを読めます。他人には教えず、漏れた可能性がある場合は提供元の設定でリセットしてください。

### パスワード付きフィード

ほとんどの公開フィードはリンク自体にアクセスキーを含んでおり、それ以外は不要です。社内やセルフホストのサーバーにあるフィードのように、ユーザー名とパスワード（HTTP Basic 認証）を求められた場合は、購読時に入力します。Mitra はパスワードをサーバーに保持し、ブラウザーに送り返すことはありません。

## 最新状態を保つ仕組み

Mitra は各購読を 15 分ごとに同期します。誰かが Mitra を開いているかどうかに関係なく同期するため、Mitra を開いてもフィードが早く取得されるわけではありません（[同期の仕組み](README.md#how-syncing-works)を参照）。同期のコストは小さく、Mitra はフィードのサーバーに変更があったかを確認し、あった場合だけカレンダーをダウンロードします。

カレンダーはフィードをそのまま映します。フィードに追加された項目は Mitra に表示され、フィードから消えた項目は消えます。

表示がおかしい場合は、**⋯** メニューの **項目を再インポート** でフィードを最初から読み直せます。フィード自体は一切変更されません。[カレンダーの再インポート](../calendars.md#re-import-a-calendar)を参照してください。

## トラブルシューティング

- Mitra が「The calendar requires a username and password」と表示する場合、フィードが保護されています。必要なユーザー名とパスワードを入力してください。
- Mitra が「No calendar was found at that address」と表示する場合、リンクに入力ミスがないか確認してください。シークレットアドレスは、所有者がリセットすると使えなくなります。
- Mitra が「The address did not return a calendar」と表示する場合、そのリンクはフィードではなく Web ページにつながっています。iCal、ICS、Subscribe と記載されたリンクを探してください。
- Mitra が「The calendar is too large to subscribe to」と表示する場合、フィードが 20 MB を超えており、Mitra は読み込みません。
