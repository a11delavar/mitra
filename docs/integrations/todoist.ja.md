---
title: Todoist
description: Todoist のプロジェクトを、双方向に同期するタスクのカレンダーとして Mitra に取り込みます。
---

Mitra はタスクのために Todoist と連携します。Todoist の各プロジェクトは Mitra のカレンダーになり、そのプロジェクトのタスクを保持します。タスクのタイトル、説明、日付、完了状態は双方向に同期されます。

アプリから API トークンで接続します。サーバー側で設定するものはありません。

## アカウントを接続する

1. Todoist で **Settings** → **Integrations** → **Developer** を開き、API トークンをコピーします。
2. Mitra でサイドバー下部の **連携を追加** を選び、**Todoist** を選択して、**Todoist API トークン** にトークンを貼り付けます。
3. **接続** を押します。プロジェクトが Todoist での色付きで一覧表示されます。別のプロジェクトの中にあるプロジェクトは、「Work · Launch」のように両方の名前で表示されます。
4. 使いたいプロジェクトを選んで **保存** を押します。

Todoist アカウントは複数接続できます。アーカイブされたプロジェクトは一覧に表示されません。

## 同期される内容

タイトル、説明、完了状態は双方向に同期され、日付も同様です。

| Todoist で | Mitra で |
| --- | --- |
| Date | タスクのスケジュール（日付または時刻） |
| Duration | タスクの予定の長さ。日付がない間は[見積もり](../planning.md#set-an-estimate) |
| Deadline | [期日](../planning.md#set-a-due-date) |
| Sub-task | [サブタスク](../subtasks.md) |

日付のないタスクは[計画タブ](../planning.md#the-planning-tab)の **日付未定** リストで待ちます。接続時には過去 12 週間に完了したタスクも取り込まれ、その後の完了もすべて同期されます。

Todoist の時刻は、どこにいてもどの時計でも同じになるフローティングか、タイムゾーンに固定されたものかのどちらかで保持されます。Mitra はどちらもそのまま維持します。フローティングの時刻は[どこでも同じ時刻](../time-zones.md#same-time-everywhere)のまま、固定されたものはそのタイムゾーンを保ちます。

締め切りと所要時間は Todoist の Pro と Business プランの機能です。無料アカウントでは、Todoist のタスクに期日、終了、見積もりはありません。時刻のあるタスクは時点になり、日のあるタスクはその日だけを占めます。トライアルの開始や終了でプランが変わると、Mitra はすべてのタスクを読み直します。締め切りは日単位なので、Mitra で時刻を付けた期日も日だけが残ります。

Mitra はタスクの優先度、ラベル、セクション、コメント、リマインダーを表示せず、Todoist 側ではそのままにします。タスクを別の Todoist カレンダーへ移動するとそのプロジェクトへ移動し、これらの情報もすべて保持されます。

タスクを Todoistで開くには、エディターの **⋯** メニューで **Todoistで開く** を選びます。Mitra でタスクを削除すると Todoist でも削除されます。

Todoist にはアプリから呼び出せる頻度の上限があるため、Mitra は約 1 分ごとに同期します（[同期の仕組み](README.md#how-syncing-works)を参照）。

## 繰り返すタスク

Todoist で繰り返すタスクは、Todoist が保持している次の日付に、ルールなしで表示されます。Mitra で完了にすると Todoist でも完了になり、Todoist がいつも通り次の日付へ進めます。別の日に移動しても次の日付が変わるだけで、ルールはそのままです。ルール自体を変えるには、Todoist でタスクを編集してください。

## Mitra だけに残るもの

Todoist には依存関係がないため、Todoist のタスク間の[依存関係](../dependencies.md)は Mitra だけに保持されます。アカウントの接続を解除するか[カレンダーを再インポート](../calendars.md#re-import-a-calendar)すると失われます。サブタスクの親は、親が同じ Todoist アカウントのタスクである限り、両方に保持されます。その場合、Todoist はサブタスクを親のプロジェクトに移動します。

## Todoist に保存できないもの

- タスクだけなので、予定や[対応可能時間](../availability.md)はありません。
- タスクは未完了か完了しかないので、**進行中** や **キャンセル済み** のステータスはありません。別の場所で進行中だったタスクは、Todoist に移すと **未着手** に戻ります。
- Mitra からタスクを繰り返しにすることはできません。
- タスクにはリマインダー、場所、参加者、添付ファイル、進捗、予定あり・空き、公開範囲がありません。

Mitra は Todoist のタスクでこれらのフィールドを隠すので、入力した内容が次の同期で消えることはありません。これらを使っている項目を Todoist に移すには、[すべての項目を別のカレンダーに移動・コピーする](../calendars.md#move-or-copy-every-entry-to-another-calendar)を参照してください。何が移せないかが先に表示されます。

## トラブルシューティング

- Todoist が API トークンを拒否したと表示される場合、**Settings** → **Integrations** → **Developer** からコピーし直してください。Todoist でリセットした場合は、Mitra でアカウントの **⋯ → 編集** を開き、新しいトークンを貼り付けます。
- プロジェクトが見つからない場合、アーカイブされている可能性があります。Todoist でアーカイブを解除したら、Mitra でアカウントの **⋯ → 編集** を開いて **更新** を押します。
