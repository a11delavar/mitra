---
title: Todoist
description: 把 Todoist 项目接入 Mitra，变成双向同步的任务日历。
---

Mitra 通过 Todoist 管理任务。你的每个 Todoist 项目都会在 Mitra 中成为一个日历，里面是该项目的任务。任务的标题、描述、日期和完成状态双向同步。

你在应用里用 API 令牌连接，服务器上无需任何设置。

## 连接账号

1. 在 Todoist 中打开 **设置** → **集成** → **开发者**，复制你的 API 令牌。
2. 在 Mitra 中，点击侧边栏底部的**添加集成**，选择 **Todoist**，把令牌粘贴到 **Todoist API 令牌**中。
3. 点击**连接**。Mitra 会列出你的项目，每个都带着它在 Todoist 中的颜色。嵌在另一个项目里的项目会带上两者的名称，例如"工作 · 发布"。
4. 选好需要的项目，然后点击**保存**。

你可以连接多个 Todoist 账号。已归档的项目不会列出。

## 同步哪些内容

标题、描述和完成状态双向同步，日期也是：

| 在 Todoist 中 | 在 Mitra 中 |
| --- | --- |
| 日期 | 任务的日程：某一天，或某个时间 |
| 时长 | 任务安排的时长；没有日期时则是它的[预估时长](../planning.md#set-an-estimate) |
| 最后期限 | 它的[截止日期](../planning.md#set-a-due-date) |
| 子任务 | 一个[子任务](../subtasks.md) |

没有日期的任务会留在[规划标签页](../planning.md#the-planning-tab)的**未安排**列表中。连接时会带来你过去十二周完成的任务，之后的每次完成也会同步过来。

Todoist 中的时间要么是浮动的，无论你在哪里，每个时钟上都一样；要么固定在某个时区。Mitra 原样保留两者：浮动的时间在 Mitra 中[各地时间相同](../time-zones.md#same-time-everywhere)，固定的时间保留它的时区。

最后期限和时长属于 Todoist 的 Pro 和 Business 套餐。免费账号下，Todoist 任务在 Mitra 中没有截止日期、结束时间和预估时长：带时间的任务是一个时刻，设在某一天的任务只占那一天。当你的套餐变化时，比如试用期开始或结束，Mitra 会重新读取所有任务。最后期限只是一天，所以你在 Mitra 中给截止日期设的时间只会保留日期。

Mitra 不显示任务的优先级、标签、分区、评论和提醒，并在 Todoist 中原样保留它们。把任务移到另一个 Todoist 日历，会把它移到对应的项目，这些内容全部保留。

要在 Todoist 中打开任务，在编辑器的 **⋯** 菜单中选择**在 Todoist 中打开**。在 Mitra 中删除任务，也会在 Todoist 中删除它。

Todoist 限制了应用调用它的频率，所以 Mitra 大约每分钟同步一次（参见[同步的工作方式](README.md#how-syncing-works)）。

## 重复的任务

在 Todoist 中重复的任务会像在 Todoist 中一样显示在它的下一个日期，不显示重复规则。在 Mitra 中完成它，也会在 Todoist 中完成它，Todoist 会像往常一样把它推到下一个日期。把它移到另一天只会改变它的下一个日期，重复规则保持不变。要修改规则本身，请在 Todoist 中编辑这个任务。

## 只留在 Mitra 中的内容

Todoist 没有依赖关系，所以 Todoist 任务之间的[依赖关系](../dependencies.md)只保存在 Mitra 中。如果你断开账号或[重新导入日历](../calendars.md#re-import-a-calendar)，它们就会丢失。子任务的父任务会同时保存在两边，前提是父任务属于同一个 Todoist 账号。这时 Todoist 会把子任务移到其父任务所在的项目。

## Todoist 无法保存的内容

- 它只保存任务，没有事件，也没有[可用时间](../availability.md)。
- 任务只有未完成和已完成两种状态，所以没有**进行中**或**已取消**状态。在别处处于进行中的任务，移到 Todoist 后会变回**待办**。
- 你不能在 Mitra 中让任务重复。
- 在 Mitra 中，任务没有提醒、地点、参与者、附件、进度、忙碌或空闲，也没有可见性。

Mitra 会在 Todoist 任务上隐藏这些字段，所以你在那里输入的内容不会在下次同步时消失。要把用到这些字段的条目移到 Todoist，参见[将所有条目移动或复制到另一个日历](../calendars.md#move-or-copy-every-entry-to-another-calendar)，它会先告诉你哪些内容带不过去。

## 故障排除

- 如果 Mitra 提示 Todoist 拒绝了 API 令牌，请从 **设置** → **集成** → **开发者** 重新复制。如果你在 Todoist 中重置过令牌，在 Mitra 中打开该账号的 **⋯ → 编辑**，粘贴新的令牌。
- 如果缺少某个项目，它可能已被归档。在 Todoist 中取消归档后，在 Mitra 中打开该账号的 **⋯ → 编辑**，然后点击**刷新**。
