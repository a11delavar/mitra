[Tempo](https://www.tempo.io/)는 Jira용 시간 기록 앱입니다. Mitra는 Jira 이슈에 기록한 시간인 **워크로그**를 캘린더에 시간이 정해진 항목으로 보여 주며, 그 시간이 들어간 회의와 작업 바로 옆에 표시합니다.

워크로그는 양방향으로 동기화됩니다. 항목을 옮기거나 길이를 바꾸면 일한 시각과 시간이 바뀌고, 설명을 편집하면 워크로그의 메모가 바뀌고, 항목을 삭제하면 워크로그가 삭제되고, 항목을 만들면 새 시간이 기록됩니다.

연결은 앱에서 API 토큰 두 개로 합니다. 서버에서 설정할 것은 없습니다.

## 작업 시간표 연결하기

Mitra에는 Tempo 토큰과 Atlassian 토큰이 하나씩 필요합니다. 시간은 Tempo가 가지고 있고, 이슈와 사용자 정보는 Jira가 알고 있기 때문입니다.

1. Tempo API 토큰을 만드세요. Jira에서 Tempo의 **Settings**(톱니바퀴 아이콘) → **Data Access** → **API integration**을 열고, **New Token**을 선택해 이름을 "Mitra"로 정한 뒤 토큰을 복사하세요.
2. [id.atlassian.com/manage-profile/security/api-tokens](https://id.atlassian.com/manage-profile/security/api-tokens)에서 **Create API token**으로 Atlassian API 토큰을 만들고 복사하세요. 두 토큰은 같은 Jira 사용자로 만드세요.
3. Mitra에서 사이드바 아래쪽의 **연동 추가**를 선택하고 **Tempo**를 고른 뒤 다음을 입력하세요.
   - **사이트 URL**: `https://your-company.atlassian.net` 같은 Atlassian 주소.
   - **Tempo API 토큰**: 1단계에서 만든 토큰.
   - **Atlassian 계정 이메일**: Atlassian 계정의 이메일 주소.
   - **Atlassian API 토큰**: 2단계에서 만든 토큰.
4. **연결**을 누르세요. Mitra가 **My worklogs** 캘린더 하나를 보여 줍니다.
5. 켜진 상태로 두고 **저장**을 누르세요.

Tempo는 앱이 호출할 수 있는 빈도를 제한하므로, Mitra는 약 1분에 한 번 동기화합니다([동기화 방식](README.md#how-syncing-works) 참고).

## 워크로그가 보이는 모습

항목의 제목은 시간이 기록된 Jira 이슈의 키와 요약입니다.

```text
ACME-1234 Code review for auth migration
```

워크로그의 메모는 항목의 설명입니다. Tempo 앱도 같은 방식으로 보여 줍니다. 이슈가 그 시간이 무엇에 관한 것인지 말해 주는 반면, 메모는 "Review" 같은 활동 이름이거나 "Working on work item ACME-1234"처럼 Jira가 대신 써 넣은 글인 경우가 많기 때문입니다.

제목은 이슈에 속하므로 저장된 워크로그에서는 편집할 수 없습니다. 캘린더 항목을 편집했다고 Mitra가 Jira 이슈 이름을 바꾸지는 않습니다. 한 일을 적으려면 설명을 편집하세요. 이슈가 삭제되었거나 더 이상 볼 수 없어서 Jira가 이슈 이름을 알려 주지 못하면, 제목에 `#`과 이슈 ID가 표시되고 항목은 계속 동작합니다.

Tempo는 워크로그를 시간대 없이 단순한 시각으로 저장합니다. Mitra는 Jira 프로필의 시간대로 이를 읽으므로 Tempo와 같은 시각에 표시됩니다.

일부 Tempo 사이트는 시작 시각을 끕니다. 그런 곳에서는 하루의 모든 워크로그가 같은 시각에 시작해 겹쳐 보이지만, 길이는 정확합니다.

## Mitra에서 시간 기록하기

**My worklogs**에 시간이 정해진 항목을 만들고, 제목 어디에든 Jira 이슈 키를 넣으세요.

| 입력한 제목 | 기록되는 이슈 |
| --- | --- |
| `ACME-1234 Team standup` | `ACME-1234` |
| `Investigating ACME-1234 regression` | `ACME-1234` |
| `ACME-1234` | `ACME-1234` |

Mitra는 볼 수 있는 Jira 프로젝트와 키를 대조합니다. 제목에 그런 키가 없거나 Jira에 그런 이슈가 없으면 아무것도 기록하지 않고 이유를 알려 줍니다.

워크로그의 메모는 설명에 쓴 내용이고, 설명을 비워 두었다면 입력한 제목 전체입니다. 시간이 기록되면 제목은 이슈의 키와 요약으로 바뀝니다. 이 교체는 기록할 때 한 번만 일어나므로, 작성하는 동안에는 제목을 편집할 수 있지만 그 뒤로는 할 수 없습니다.

> [!TIP]
> 전에 기록한 적이 있는 이슈에 시간을 기록하려면 그 이슈의 항목 하나를 복제하세요. <kbd>Alt</kbd>(Mac에서는 <kbd>⌥</kbd>)를 누른 채 새 시각으로 끌거나, 편집기 **⋯** 메뉴에서 **복제**를 선택하면 됩니다.

## 워크로그 바꾸기

옮기기, 길이 바꾸기, 삭제, 설명 편집은 바로 Tempo에 반영됩니다. 알아 둘 점이 몇 가지 있습니다.

- 워크로그는 자신의 이슈에 남습니다. Tempo는 워크로그를 다른 이슈로 옮길 수 없으므로, 다른 곳에 시간을 기록하려면 항목을 삭제하고 올바른 키로 새로 만드세요.
- Mitra는 워크로그를 바꿀 때 청구 가능 시간이나 작업 속성 같은 Tempo 자체의 세부 정보를 그대로 유지합니다.
- Tempo에서 작업 시간표 기간이 마감되었거나 승인되면, Tempo는 그 기간의 워크로그 추가, 변경, 삭제를 거부합니다.

Jira에서 이슈를 열려면 편집기 **⋯** 메뉴에서 **Jira에서 열기**를 선택하세요.

## 워크로그에 담을 수 없는 것

워크로그는 한 이슈에 기록된, 하루 안의 시간 구간입니다. 그래서 Tempo 캘린더에는 시간이 정해진 항목만 담깁니다. 종일 항목, 반복, 알림, 장소, 참석자, [첨부 파일](../attachments.md), 관계, 바쁨 또는 한가함, 공개 상태, [가용 시간](../availability.md)은 담을 수 없습니다. Mitra는 워크로그에서 이 필드들을 숨깁니다.

## 문제 해결

- Mitra가 "Tempo rejected the API token"이라고 하면 새 Tempo API 토큰을 만들어 계정의 **⋯ → 편집**에서 입력하세요.
- Mitra가 "Jira rejected the e-mail and API token"이라고 하면 이메일 주소가 API 토큰을 만든 Atlassian 계정의 것인지 확인하세요.
- 워크로그가 엉뚱한 시각에 표시되면 Jira 프로필의 시간대(**Account settings** → **Time zone**)를 확인하세요. 시간대를 바꾼 뒤에는 **My worklogs**의 **⋯** 메뉴에서 **항목 다시 가져오기**를 사용해 이미 있는 워크로그도 함께 옮기세요.
- 워크로그가 매일 같은 시각에 겹쳐 보이면 Tempo 사이트에서 시작 시각을 끈 것입니다. 시간은 여전히 정확합니다.
