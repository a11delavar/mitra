很多日历是公开发布的，而不是共享给你的：法定节假日、体育赛程、学校学期、工作中某个工具提供的订阅源，或者你自己的 Google 或 Outlook 日历的私密地址。这些日历不需要登录，只要通过链接订阅即可。

**日历订阅**会把这样一个链接作为一个独立的日历接入 Mitra，其中包括它的日程，如果有任务的话也包括任务。

订阅是只读的。订阅源存放在另一台服务器上，不接受修改，所以 Mitra 只显示它发布的内容，从不写回。你仍然可以重命名这个日历、更改颜色、调整顺序或隐藏它，参见[只读日历](../calendars.md#read-only-calendars)。如果想保留一份可以编辑的副本，请在它的 **⋯** 菜单中使用**将条目复制到…**。

## 订阅日历

1. 点击侧边栏底部的**添加集成**，然后选择**日历订阅**。
2. 把链接粘贴到**日历 URL** 中。链接要么是 `webcal://` 地址（“订阅”按钮通常给出的就是这种），要么是 `https://` 地址，通常以 `.ics` 结尾。
3. **用户名（可选）** 和**密码（可选）** 留空即可，除非订阅源要求填写（参见[需要密码的订阅源](#feeds-with-a-password)）。
4. 点击**连接**。Mitra 会读取订阅源并列出其中的日历。
5. 保持它开启，然后点击**保存**。

一个链接对应一个日历。要订阅多个日历，请为每个日历分别添加订阅。

日历的名称取自订阅源；如果订阅源带有颜色，颜色也一样。你可以在侧边栏中重命名它，你起的名字会一直保留，直到订阅源自己更改日历名称。

如果你已[把 Mitra 设为默认日历应用](../calendar-files.md)，在网页上点击 `webcal://` 链接时，就会打开这个表单，并自动填好链接。

### 在哪里找到日历链接

| 服务 | 在哪里找 |
| --- | --- |
| Google 日历 | 在日历设置中，**集成日历**（Integrate calendar）→ **iCal 格式的私密地址**（Secret address in iCal format） |
| Outlook 和 Microsoft 365 | **共享**（Share）→ **发布日历**（Publish a calendar），然后复制 ICS 链接 |
| iCloud | 右键点击日历 → **共享日历**（Share Calendar）→ **公开日历**（Public Calendar） |
| Nextcloud | 日历的 **⋯** 菜单 → **复制订阅链接**（Copy subscription link） |
| 公共日历 | 大多数节假日、体育和学校网站都会提供 `.ics` 链接 |

> [!CAUTION]
> 私密地址就是以链接形式存在的密码：任何拿到它的人都能读取这个日历。请不要外传；如果不慎泄露，请在服务提供商的设置中重置它。

### 需要密码的订阅源

大多数公开发布的订阅源把访问密钥直接放在链接里，不需要其他信息。如果某个订阅源（比如公司或自托管服务器上的订阅源）要求输入用户名和密码（HTTP Basic 认证），请在订阅时填写。Mitra 会把密码保存在服务器上，绝不会把它发回你的浏览器。

## 如何保持更新

无论是否有人打开 Mitra，它都会每 15 分钟同步一次每个订阅，所以打开 Mitra 并不会让订阅源更早刷新（参见[同步的工作方式](README.md#how-syncing-works)）。同步的开销很小：Mitra 会先询问订阅源的服务器内容是否有变化，只有变化时才下载日历。

日历与订阅源保持一致。订阅源中新增的条目会出现在 Mitra 中，被移除的条目也会随之消失。

如果日历看起来不对，可以在它的 **⋯** 菜单中选择**重新导入条目**，从头重新读取订阅源。订阅源本身不会受到任何影响。参见[重新导入日历](../calendars.md#re-import-a-calendar)。

## 故障排除

- 如果 Mitra 提示“The calendar requires a username and password”，说明订阅源受到保护。请填写它所需的用户名和密码。
- 如果 Mitra 提示“No calendar was found at that address”，请检查链接是否有拼写错误。另外，私密地址被所有者重置后也会失效。
- 如果 Mitra 提示“The address did not return a calendar”，说明链接指向的是网页，而不是订阅源。请在网页上找标为 iCal、ICS 或“订阅”的链接。
- 如果 Mitra 提示“The calendar is too large to subscribe to”，说明订阅源超过了 20 MB，Mitra 无法读取。
