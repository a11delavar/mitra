---

Mitra는 작업을 위해 Todoist에 연결합니다. Todoist 프로젝트 하나하나가 Mitra에서 그 작업을 담는 캘린더가 됩니다. 작업의 제목, 설명, 날짜, 완료 여부가 양방향으로 동기화됩니다.

연결은 앱에서 API 토큰으로 합니다. 서버에서 설정할 것은 없습니다.

## 계정 연결하기

1. Todoist에서 **설정** → **통합** → **개발자**를 열고 API 토큰을 복사하세요.
2. Mitra에서 사이드바 아래쪽의 **연동 추가**를 고르고 **Todoist**를 고른 다음, **Todoist API 토큰**에 토큰을 붙여 넣으세요.
3. **연결**을 누르세요. Mitra가 프로젝트 목록을 Todoist의 색상 그대로 보여 줍니다. 다른 프로젝트 안에 있는 프로젝트는 "Work · Launch"처럼 두 이름을 합쳐 부릅니다.
4. 원하는 프로젝트를 고르고 **저장**을 누르세요.

Todoist 계정은 둘 이상 연결할 수 있습니다. 보관된 프로젝트는 목록에 나오지 않습니다.

## 동기화되는 내용

제목, 설명, 완료 여부가 양방향으로 동기화되며, 날짜도 마찬가지입니다.

| Todoist에서 | Mitra에서 |
| --- | --- |
| 날짜 | 작업의 일정: 하루 또는 시각 |
| 소요 시간 | 작업이 잡힌 시간의 길이, 날짜가 없는 동안에는 [예상 시간](../planning.md#set-an-estimate) |
| 기한 | [마감일](../planning.md#set-a-due-date) |
| 하위 작업 | [하위 작업](../subtasks.md) |

날짜가 없는 작업은 [계획 탭](../planning.md#the-planning-tab)의 **날짜 미정** 목록에서 기다립니다. 최근 12주 안에 완료한 작업은 연결할 때 함께 들어오고, 그 뒤의 완료는 모두 들어옵니다.

Todoist는 시각을 어디에 있든 모든 시계에서 같은 부동 시각으로 보관하거나, 특정 시간대에 고정해 보관합니다. Mitra는 둘 다 그대로 유지합니다. 부동 시각은 [어디서나 같은 시각](../time-zones.md#same-time-everywhere)으로 남고, 고정된 시각은 시간대를 유지합니다.

기한과 소요 시간은 Todoist의 Pro와 Business 요금제에 포함됩니다. 무료 계정에서는 Todoist 작업에 Mitra의 마감일, 종료, 예상 시간이 없습니다. 시각이 있는 작업은 한 시점이고, 날짜에 있는 작업은 그 하루만 차지합니다. 체험 기간이 시작되거나 끝나는 등 요금제가 바뀌면 Mitra가 모든 작업을 다시 읽습니다. 기한은 하루 단위이므로, Mitra에서 마감일에 시각을 주어도 날짜만 남습니다.

Mitra는 작업의 우선순위, 라벨, 섹션, 댓글, 알림을 보여 주지 않으며 Todoist에 있는 그대로 둡니다. 작업을 다른 Todoist 캘린더로 옮기면 그 프로젝트로 옮겨지고, 이런 정보는 모두 유지됩니다.

Todoist에서 작업을 열려면 편집기의 **⋯** 메뉴에서 **Todoist에서 열기**를 고르세요. Mitra에서 작업을 삭제하면 Todoist에서도 삭제됩니다.

Todoist는 앱이 호출할 수 있는 빈도를 제한하므로, Mitra는 대략 1분에 한 번 동기화합니다([동기화 방식](README.md#how-syncing-works) 참고).

## 반복 작업

Todoist에서 반복되는 작업은 Todoist가 보관하는 대로 다음 날짜에 규칙 없이 표시됩니다. Mitra에서 완료하면 Todoist에서도 완료되고, Todoist는 언제나처럼 그다음 날짜로 넘깁니다. 다른 날로 옮기면 다음 날짜만 바뀌고 규칙은 그대로입니다. 규칙 자체를 바꾸려면 Todoist에서 작업을 편집하세요.

## Mitra에만 남는 것

Todoist에는 종속 관계가 없으므로, Todoist 작업 사이의 [종속 관계](../dependencies.md)는 Mitra에만 보관됩니다. 계정 연결을 끊거나 [캘린더를 다시 가져오면](../calendars.md#re-import-a-calendar) 사라집니다. 하위 작업의 상위 작업은 그 상위 작업이 같은 Todoist 계정의 작업이라면 양쪽에 보관됩니다. 그러면 Todoist가 하위 작업을 상위 작업의 프로젝트로 옮깁니다.

## Todoist가 담지 못하는 것

- 작업만 담으므로 일정과 [가용 시간](../availability.md)이 없습니다.
- 작업은 열려 있거나 완료되었거나 둘 중 하나이므로 **진행 중**이나 **취소됨** 상태가 없습니다. 다른 곳에서 진행 중이던 작업을 Todoist로 옮기면 **할 일**로 돌아갑니다.
- Mitra에서 작업을 반복하게 만들 수 없습니다.
- Mitra에서 작업에 알림, 장소, 참석자, 첨부 파일, 진행률, 바쁨 또는 한가함, 공개 상태가 없습니다.

Mitra는 Todoist 작업에서 이 필드들을 숨기므로, 거기 입력한 내용이 다음 동기화 때 사라지는 일은 없습니다. 이런 필드를 쓰는 항목을 Todoist로 옮기려면 [모든 항목을 다른 캘린더로 옮기거나 복사하기](../calendars.md#move-or-copy-every-entry-to-another-calendar)를 참고하세요. 무엇이 옮겨지지 못하는지 먼저 보여 줍니다.

## 문제 해결

- Todoist가 API 토큰을 거부했다고 Mitra가 알리면 **설정** → **통합** → **개발자**에서 다시 복사하세요. Todoist에서 토큰을 재설정했다면 Mitra에서 계정의 **⋯ → 편집**을 열고 새 토큰을 붙여 넣으세요.
- 프로젝트가 보이지 않으면 보관된 것일 수 있습니다. Todoist에서 보관을 해제한 뒤 Mitra에서 계정의 **⋯ → 편집**을 열고 **새로 고침**을 누르세요.
