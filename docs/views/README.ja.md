Mitraは同じ項目を5つのビューで表示します。

- [週ビュー](week.md)：1時間ごとに表示され、1日が1列になります。
- [月ビュー](month.md)：週が行になり、項目はその日をまたぐバーとして表示されます。
- [年ビュー](year.md)：各月が日付の1行になります。
- [タイムラインビュー](timeline.md)：未完了のタスクが1行ずつ並びます。
- [テーブルビュー](table.md)：項目が行として並び、並べ替えや絞り込み、まとめて変更ができます。

ビューはページヘッダーのビュー切り替えから選ぶか、キーを押します。<kbd>W</kbd>、<kbd>M</kbd>、<kbd>Y</kbd>、<kbd>L</kbd>、<kbd>S</kbd>です。切り替えても、見ていた日付はそのままです。[設定](../settings.md)の **既定のビュー** で、Mitraを開いたときに表示するビューを決められます。

## 時間を移動する

テーブル以外のすべてのビューでは、**今日** の横の矢印で、そのビューの期間(1週間、1か月、1年)ごとに前後へ移動できます。<kbd>T</kbd>で今日に戻り、<kbd>G</kbd>で任意の日付へジャンプします。普通にスクロールするだけでも移動できます。

## ズーム

<kbd>Ctrl</kbd>を押しながらスクロールするか、2本指でピンチすると、週・月・年・タイムラインの各ビューをズームできます。ビューの端にある目盛りの上でスクロールすれば、<kbd>Ctrl</kbd>なしでもズームできます。目盛りは、週ビューでは時間、月ビューでは週番号、年ビューでは月名、タイムラインでは日付です。各ビューのズームは、使っているデバイスごとに記憶されます。

## タッチスクリーンの場合

項目を0.5秒ほど長押しすると移動やサイズ変更ができ、何もない場所を長押しすると新しい項目を作成できます。普通のスワイプはスクロールになるので、誤って動かしてしまうことはありません。

## 見ているものを共有する

ブラウザーのアドレスには、表示中のビューと日付、開いている項目が含まれているので、ブックマークや誰かに送ったリンクを開けば、同じ場所が開きます。設定ページも同じ仕組みです。
