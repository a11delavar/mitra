Mitra 用五种视图显示同样的条目：

- [周视图](week.md)：按小时显示，每天一列。
- [月视图](month.md)：每周一行，条目以横条形式横跨它所在的日期。
- [年视图](year.md)：每个月一行日期。
- [时间线](timeline.md)：未完成的任务每个一行。
- [表格](table.md)：条目按行列出，可以排序、筛选，还能一次修改多个条目。

在页面顶栏的视图切换器中选择视图，或者按对应的按键：<kbd>W</kbd>、<kbd>M</kbd>、<kbd>Y</kbd>、<kbd>L</kbd> 或 <kbd>S</kbd>。切换视图时，你正在查看的日期保持不变。[设置](../settings.md)中的 **默认视图** 决定 Mitra 打开时显示哪个视图。

## 在时间中移动

除表格外，在其他每个视图中，**今天** 旁边的箭头都会按该视图的周期前后翻动：一周、一个月或一年。按 <kbd>T</kbd> 回到今天，按 <kbd>G</kbd> 跳转到任意日期。直接滚动也可以。

## 缩放

按住 <kbd>Ctrl</kbd> 滚动，或用双指捏合，可以缩放周视图、月视图、年视图和时间线视图。如果在视图边缘的刻度上滚动，不按 <kbd>Ctrl</kbd> 也能缩放。这些刻度分别是周视图的小时、月视图的周数、年视图的月份名称和时间线的日期。每个视图都会在你当前使用的设备上记住它的缩放比例。

## 在触摸屏上

按住一个条目半秒钟，就可以移动它或调整它的长短；在空白处按住，则可以新建条目。普通的滑动只会滚动视图，所以不会误移任何东西。

## 分享你看到的内容

浏览器地址栏中的网址记录了当前的视图、日期以及你打开的条目，所以无论是书签，还是你发给别人的链接，打开后都会回到同一个位置。设置页面也是如此。
