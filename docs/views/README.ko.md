Mitra는 같은 항목을 다섯 가지 보기로 보여 줍니다.

- [주 보기](week.md): 시간 단위로, 하루에 한 열씩 보여 줍니다.
- [월 보기](month.md): 주가 한 행이고, 항목은 해당 날짜에 걸친 막대로 보여 줍니다.
- [연도 보기](year.md): 각 달을 날짜 한 행으로 보여 줍니다.
- [타임라인 보기](timeline.md): 열린 작업을 한 행에 하나씩 보여 줍니다.
- [표 보기](table.md): 항목을 행으로 보여 주며, 정렬하고 필터링하고 여러 개를 한 번에 바꿀 수 있습니다.

페이지 헤더의 보기 선택기에서 보기를 고르거나 해당 키를 누르세요. <kbd>W</kbd>, <kbd>M</kbd>, <kbd>Y</kbd>, <kbd>L</kbd>, <kbd>S</kbd>입니다. 보기를 바꿔도 보고 있던 날짜는 그대로 유지됩니다. [설정](../settings.md)의 **기본 보기**에서 Mitra가 처음 열릴 때의 보기를 정합니다.

## 시간 이동하기

표 보기를 제외한 모든 보기에서 **오늘** 옆의 화살표는 보기 단위만큼, 즉 한 주, 한 달, 한 해씩 앞뒤로 이동합니다. <kbd>T</kbd>는 오늘로 돌아가고, <kbd>G</kbd>는 원하는 날짜로 이동합니다. 그냥 스크롤해도 됩니다.

## 확대/축소

<kbd>Ctrl</kbd> 키를 누른 채 스크롤하거나 두 손가락으로 오므리고 벌려서 주, 월, 연도, 타임라인 보기를 확대하거나 축소하세요. 보기의 가장자리 위에서 스크롤하면 <kbd>Ctrl</kbd> 없이도 확대/축소됩니다. 주 보기의 시간, 월 보기의 주 번호, 연도 보기의 월 이름, 타임라인의 날짜가 그 가장자리입니다. 각 보기는 사용하는 기기에서 확대/축소 상태를 기억합니다.

## 터치스크린에서

항목을 0.5초 동안 길게 누르면 옮기거나 크기를 바꿀 수 있고, 빈 곳을 길게 누르면 항목을 만들 수 있습니다. 그냥 밀면 스크롤되므로 실수로 무언가를 옮기는 일은 없습니다.

## 보고 있는 화면 공유하기

브라우저 주소에는 보기, 날짜, 열려 있는 항목이 담겨 있으므로, 북마크나 다른 사람에게 보낸 링크를 열면 같은 곳이 열립니다. 설정 페이지도 마찬가지입니다.
