La vista mensual muestra las semanas como filas, con cada entrada como una barra a lo largo de los días que cubre. Ábrela con <kbd>M</kbd>.

<picture>
  <source media="(prefers-color-scheme: dark)" srcset="../../assets/screenshots/month-detail-dark.webp">
  <img src="../../assets/screenshots/month-detail-light.webp" alt="La vista mensual, con entradas como barras a lo largo de las semanas" />
</picture>

Lo que ocurre muy a menudo, como un entrenamiento diario, no recibe una barra cada vez. Se muestra como pequeñas marcas bajo los días; consulta [Rutinas](../routines.md).

Cuando un día contiene más entradas de las que caben, el resto se desvanece en la parte inferior de su fila. Acércate con <kbd>Ctrl</kbd> y desplazamiento para dar más espacio a cada semana, o aléjate para ver hasta nueve semanas a la vez.

Los números de semana recorren el lateral. Haz clic en uno para abrir esa semana en la [vista semanal](week.md).

Arrastra por varios días para crear una entrada de todo el día, arrastra una entrada a otro día para moverla, o arrastra su extremo para alargarla o acortarla.
