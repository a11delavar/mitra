La vista anual muestra cada mes como una fila de días, así que el año entero cabe en una pantalla. Es el lugar para encontrar una semana libre o para ver cómo encaja un viaje con todo lo que lo rodea. Ábrela con <kbd>Y</kbd>.

<picture>
  <source media="(prefers-color-scheme: dark)" srcset="../../assets/screenshots/year-detail-dark.webp">
  <img src="../../assets/screenshots/year-detail-light.webp" alt="La vista anual, con cada mes como una fila de días" />
</picture>

Las entradas se muestran como barras a lo largo de sus días. Lo que vuelve a menudo, incluso cada mes, se muestra como pequeñas marcas; consulta [Rutinas](../routines.md).

Arrastra por varios días para crear una entrada de todo el día, y arrastra una entrada para moverla o su extremo para cambiar sus días. Haz clic en el nombre de un mes para abrirlo en la [vista mensual](month.md).

Haz zoom con <kbd>Ctrl</kbd> y desplazamiento para dar más espacio a las filas.
