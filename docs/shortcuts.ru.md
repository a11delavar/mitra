---

Нажмите <kbd>?</kbd> в любом месте календаря, чтобы открыть список быстрых клавиш. Он всегда соответствует той версии, которая у вас запущена. Клавиши следуют соглашениям веб-календарей, таких как Google Календарь, Notion Calendar и Proton Calendar, поэтому привычные сочетания работают и здесь.

## Виды

| Действие | Клавиши |
| --- | --- |
| Вид недели | <kbd>W</kbd> |
| Вид месяца | <kbd>M</kbd> |
| Вид года | <kbd>Y</kbd> |
| Вид временной шкалы | <kbd>L</kbd> |
| Вид таблицы | <kbd>S</kbd> |

## Навигация

| Действие | Клавиши |
| --- | --- |
| Перейти к сегодняшнему дню | <kbd>T</kbd> |
| На неделю, месяц или год вперёд | <kbd>→</kbd> |
| На неделю, месяц или год назад | <kbd>←</kbd> |
| Перейти к определённой дате | <kbd>G</kbd> |

## Записи

| Действие | Клавиши |
| --- | --- |
| Создать запись | <kbd>C</kbd> |
| Удалить открытую запись | <kbd>Delete</kbd> или <kbd>Backspace</kbd> |
| Удалить только эту запись из серии | <kbd>Ctrl</kbd> <kbd>Delete</kbd> |
| Переместить или изменить длительность только этой записи из серии | отпустить запись, удерживая <kbd>Ctrl</kbd> |
| Дублировать запись | отпустить запись, удерживая <kbd>Alt</kbd> |
| Выбрать статус задачи | <kbd>Alt</kbd> + нажатие на флажок или нажатие на него правой кнопкой мыши |
| Изменить масштаб вида | <kbd>Ctrl</kbd> + прокрутка |

## Общие

| Действие | Клавиши |
| --- | --- |
| Искать записи или выполнить команду | <kbd>/</kbd>, <kbd>Ctrl</kbd> <kbd>P</kbd> или <kbd>Ctrl</kbd> <kbd>K</kbd> |
| Быстрые клавиши | <kbd>?</kbd> |
| [Настройки](settings.md) | <kbd>Ctrl</kbd> <kbd>,</kbd> |
| [Показать только один календарь](calendars.md#show-only-one-calendar) или вернуть остальные | <kbd>Alt</kbd> + нажатие на его значок глаза на боковой панели |
| Закрыть или вернуться назад | <kbd>Esc</kbd> |

> [!NOTE]
> На Mac вместо <kbd>Ctrl</kbd> везде используется <kbd>⌘</kbd>, вместо <kbd>Alt</kbd> используется <kbd>⌥</kbd>, а вместо <kbd>Delete</kbd> используется <kbd>⌫</kbd> (<kbd>Backspace</kbd> тоже везде удаляет).

Однобуквенные сочетания никогда не срабатывают, пока вы вводите текст в поле.

## Палитра команд

Нажмите <kbd>/</kbd>, <kbd>Ctrl</kbd> + <kbd>K</kbd> или <kbd>Ctrl</kbd> + <kbd>P</kbd>, чтобы найти запись или выполнить команду; все три сочетания делают одно и то же. Поиск идёт по названиям, описаниям и местам во всех ваших календарях, а не только по дням на экране, и показывает повторяющуюся запись один раз. Записи из скрытых календарей отображаются приглушёнными. Если выбрать запись, Mitra перейдёт к её дате и откроет её, снова показав её календарь, если он был скрыт. Команды охватывают виды, навигацию, создание записей, ваши календари и настройки, а рядом с каждой указаны её клавиши, так что их можно запоминать по ходу работы.
