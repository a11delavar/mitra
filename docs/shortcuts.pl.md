description: "Obsługuj aplikację Mitra z klawiatury: widoki, nawigacja, wpisy i paleta poleceń."

Naciśnij <kbd>?</kbd> w dowolnym miejscu kalendarza, aby otworzyć listę skrótów. Zawsze odpowiada ona wersji, której używasz. Klawisze są zgodne z konwencjami kalendarzy internetowych, takich jak Kalendarz Google, Notion Calendar i Proton Calendar, więc to, co już znasz, zadziała i tutaj.

## Widoki

| Działanie | Klawisze |
| --- | --- |
| Widok tygodnia | <kbd>W</kbd> |
| Widok miesiąca | <kbd>M</kbd> |
| Widok roku | <kbd>Y</kbd> |
| Widok osi czasu | <kbd>L</kbd> |
| Widok tabeli | <kbd>S</kbd> |

## Nawigacja

| Działanie | Klawisze |
| --- | --- |
| Przejdź do dzisiaj | <kbd>T</kbd> |
| Tydzień / miesiąc / rok do przodu | <kbd>→</kbd> |
| Tydzień / miesiąc / rok wstecz | <kbd>←</kbd> |
| Przejdź do konkretnej daty | <kbd>G</kbd> |

## Wpisy

| Działanie | Klawisze |
| --- | --- |
| Utwórz wpis | <kbd>C</kbd> |
| Usuń otwarty wpis | <kbd>Delete</kbd> lub <kbd>Backspace</kbd> |
| Usuń tylko ten wpis z serii | <kbd>Ctrl</kbd> <kbd>Delete</kbd> |
| Przenieś lub zmień rozmiar tylko tego wpisu z serii | przytrzymaj <kbd>Ctrl</kbd> podczas upuszczania |
| Duplikuj wpis | przytrzymaj <kbd>Alt</kbd> podczas upuszczania |
| Wybierz status zadania | <kbd>Alt</kbd> + kliknięcie pola wyboru albo kliknięcie go prawym przyciskiem myszy |
| Powiększ lub pomniejsz widok | <kbd>Ctrl</kbd> + przewijanie |

## Ogólne

| Działanie | Klawisze |
| --- | --- |
| Szukaj wpisów lub uruchom polecenie | <kbd>/</kbd> lub <kbd>Ctrl</kbd> <kbd>P</kbd> lub <kbd>Ctrl</kbd> <kbd>K</kbd> |
| Skróty klawiszowe | <kbd>?</kbd> |
| [Ustawienia](settings.md) | <kbd>Ctrl</kbd> <kbd>,</kbd> |
| [Pokaż tylko jeden kalendarz](calendars.md#show-only-one-calendar) lub przywróć pozostałe | <kbd>Alt</kbd> + kliknięcie ikony oka w panelu bocznym |
| Zamknij lub wróć | <kbd>Esc</kbd> |

> [!NOTE]
> Na Macu <kbd>Ctrl</kbd> oznacza wszędzie <kbd>⌘</kbd>, a <kbd>Alt</kbd> oznacza <kbd>⌥</kbd>. Klawisz <kbd>⌫</kbd> zastępuje <kbd>Delete</kbd> (wszędzie usuwa też <kbd>Backspace</kbd>).

Skróty jednoliterowe nigdy nie działają podczas pisania w polu tekstowym.

## Paleta poleceń

Naciśnij <kbd>/</kbd>, <kbd>Ctrl</kbd> + <kbd>K</kbd> lub <kbd>Ctrl</kbd> + <kbd>P</kbd>, aby wyszukać wpisy albo uruchomić polecenie; wszystkie trzy skróty działają tak samo. Wyszukiwanie przegląda tytuły, opisy i lokalizacje we wszystkich twoich kalendarzach, nie tylko w dniach widocznych na ekranie, a wpis cykliczny pokazuje raz. Wpisy z ukrytych kalendarzy są przyciemnione. Wybranie wpisu przenosi do jego daty i otwiera go, a jeśli jego kalendarz był ukryty, znów go pokazuje. Polecenia obejmują widoki, nawigację, nowe wpisy, twoje kalendarze i ustawienia, a obok każdego widać jego skrót, więc możesz uczyć się skrótów na bieżąco.
