カレンダーファイル(`.ics`)と購読リンク(`webcal://`)は、ウェブ上で予定が配られる形です: メールに添付された招待、予約ページの「カレンダーに追加」ボタン、チームの試合日程の「購読」リンクなど。Mitra をインストールすればそのどちらも開けます。パソコンがそれらを開くときのアプリを Mitra にすることもできます。

> [!NOTE]
> ファイルとリンクを開くには、パソコン上の Chrome、Edge、Brave、Opera など Chromium 系ブラウザーから Mitra を[アプリとしてインストール](install-app.md)しておく必要があります。どのブラウザーでも、`.ics` ファイルを Mitra の上へドラッグすることはできます。

## Mitra をデフォルトのアプリにする

まず Mitra をインストールします。初めてカレンダーファイルやリンクが Mitra を開こうとしたとき、ブラウザーが Mitra に処理を許可するか尋ねることがあります。**許可** を選んでください。それから、`.ics` ファイルを Mitra で開くようシステムに設定します。

Windows では、エクスプローラーで `.ics` ファイルを右クリックし、**プログラムから開く → 別のプログラムを選択** を選びます。**Mitra** を選んでから **常に** を選びます。あとから **設定 → アプリ → デフォルトのアプリ** で変更することもできます。

macOS では、Finder で `.ics` ファイルを Control キーを押しながらクリックし、**情報を見る** を選びます。**開くアプリケーション** で **Mitra** を選び、**すべてを変更…** をクリックして確定します。

Linux では、ファイルマネージャーで `.ics` ファイルを右クリックして **プロパティ → 開くアプリケーション** を開きます。**Mitra** を選び、デフォルトに設定します。

Mitra がすでに開いていれば、開いたファイルやリンクは新しいウィンドウではなくそのウィンドウへ行きます。

## カレンダーファイルを追加する

`.ics` ファイルを Mitra で開くか、デスクトップやファイルマネージャーから Mitra の上へドラッグします。ドラッグは、何もインストールしなくても通常のブラウザータブでも使えます。複数のファイルは順番に開かれます。

Mitra はどのカレンダーに項目を追加するか尋ねます。追加する前に、そのカレンダーに保存できないものを示します: 取り込まれない項目や、リマインダーを持てないカレンダーでリマインダーを失う項目のように、一部の項目が失う情報です。進めるには、**12件の項目を追加** のように追加される件数を示したボタンを押します。別のカレンダーを選ぶには、矢印で戻ります。ファイルそのものが変わることはありません。

各項目は新しいコピーとして追加されるので、同じファイルを2回追加するとすべての項目が2つずつになります。カレンダーにすでにある項目が上書きされることはありません。

同じファイル内の項目どうしのサブタスクや依存関係は、インポート後も維持されます。繰り返しシリーズは、削除済みの回が削除されたまま保たれます。別の日に移した会議のように個別の回を編集したシリーズは取り込まれません。Mitra は編集を含んだままシリーズを追加できないからです。

追加が途中で失敗したら、Mitra は追加済みの項目を取り消すので、ファイルの一部だけが中途半端に残ることはありません。取り消せなかった項目があるときは、手動で削除すべき件数を知らせます。

## webcal リンクから購読する

スポーツの試合日程、学校の学期、祝日など、カレンダーを購読できるサイトはたいてい `webcal://` アドレスへのリンクを持っています。そのリンクをクリックすると、Mitra が **カレンダー購読** フォームをアドレス入力済みの状態で開きます。確認し、フィードが必要とするなら **ユーザー名(任意)** と **パスワード(任意)** を入力して **接続** を押します。それからカレンダーをオンにして **保存** を押します。

リンクをクリックしただけでは購読されません: Mitra がフィードを取得するのは **接続** を押したときだけです。

購読は、Mitra がフィードから最新の状態に保つ1つの読み取り専用カレンダーです。仕組みは[カレンダー購読](integrations/subscriptions.md)を参照してください。
