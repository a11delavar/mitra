---
title: アプリをインストールする
description: "Mitra をコンピューター、Android スマートフォン、iPhone、iPad にアプリとしてインストールし、専用のウィンドウで開けるようにします。"
---

Mitra はブラウザーで動きますが、アプリとしてインストールすることもできます。アプリストアからは何も入手しません。ブラウザーが Mitra に専用のウィンドウとアイコンを与え、Dock、タスクバー、スタートメニュー、ホーム画面から他のアプリと同じように開けます。

インストールには3つの利点があります。

- Mitra がブラウザーのタブから離れた専用ウィンドウで開き、通知も Mitra 自身の名前とアイコンで表示されます。
- iPhone や iPad では、[リマインダー](reminders.md)を受け取る唯一の方法です。
- コンピューターでは、Mitra が `.ics` ファイルや `webcal://` リンクを開けるようになります。[カレンダーファイル](calendar-files.md)を参照してください。

インストールされたアプリの名前は常に Mitra で、アイコンも Mitra のものです。サーバーに[独自の名前](configuration.md#name-your-instance)が付いていても変わりません。

## コンピューターで

Chrome、Edge、その他の Chromium ベースのブラウザーでは、Mitra を開いてアドレスバー右端のインストールアイコンをクリックします。ブラウザーが Mitra のインストールを提案するときは、サイドバー下部にも**アプリとしてインストール**ボタンが表示されます。ブラウザーのメニューからも実行できます。Chrome では**キャスト、保存、共有 → ページをアプリとしてインストール**、Edge では**アプリ → このサイトをアプリとしてインストール**です。

Mac の Safari では**ファイル → Dock に追加**を選びます。

インストール後、Mitra は専用ウィンドウで開きます。カレンダーファイルやリンクを開いたときにそのウィンドウがすでに開いていれば、2つ目を開かずにそれを前面に出します。

## Android で

Chrome で Mitra を開き、ブラウザーメニュー(**⋮**)から**アプリをインストール**または**ホーム画面に追加**を選びます。すると Mitra が他のアプリと一緒に表示されるようになります。

Android ではブラウザーでもリマインダーが動くので、インストールするかどうかは任意です。

## iPhone と iPad で

Safari で Mitra を開き、共有ボタンをタップして**ホーム画面に追加**を選びます。以降はホーム画面のアイコンから Mitra を開きます。

iPhone と iPad では、iOS/iPadOS 16.4 以降、通知はインストールしたアプリでのみ動作します。インストールしたアプリの中から許可してください。Safari とアプリは別物で、リマインダーを受け取れるのはアプリだけです。

> [!NOTE]
> サーバーが Cookie でサインインさせるリバースプロキシの後ろにある場合でも、インストールは動作します。Mitra はアプリの定義(ウェブアプリマニフェスト)を Cookie 付きで要求するので、プロキシはそのリクエストを通します。
