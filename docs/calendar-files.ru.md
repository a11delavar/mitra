Именно в виде файлов календаря (`.ics`) и ссылок для подписки (`webcal://`) интернет раздаёт события: приглашение во вложении письма, кнопка «Добавить в календарь» на странице бронирования, ссылка «Подписаться» на расписание матчей команды. Установленный Mitra умеет открывать и то и другое, и его можно сделать приложением, которое компьютер использует для них.

> [!NOTE]
> Чтобы открывать файлы и ссылки, Mitra нужно [установить как приложение](install-app.md) на компьютере из браузера на основе Chromium, например Chrome, Edge, Brave или Opera. В любом браузере файл `.ics` по-прежнему можно перетащить в Mitra.

## Как сделать Mitra приложением по умолчанию

Сначала установите Mitra. Когда файл или ссылка календаря впервые откроет его, браузер может спросить, можно ли Mitra их обрабатывать: выберите **Разрешить**. Затем укажите системе открывать файлы `.ics` в Mitra.

В Windows нажмите правой кнопкой на файл `.ics` в Проводнике и выберите **Открыть с помощью → Выбрать другое приложение**. Выберите **Mitra**, затем **Всегда**. Изменить это можно и позже в разделе **Параметры → Приложения → Приложения по умолчанию**.

В macOS нажмите на файл `.ics` в Finder, удерживая Control, и выберите **Свойства**. В разделе **Открывать в программе** выберите **Mitra**, затем нажмите **Изменить все…** и подтвердите.

В Linux нажмите правой кнопкой на файл `.ics` в файловом менеджере и откройте **Свойства → Открывать с помощью**. Выберите **Mitra** и назначьте его приложением по умолчанию.

Если Mitra уже открыт, открываемый файл или ссылка попадёт в это окно, а не откроет второе.

## Как добавить файл календаря

Откройте файл `.ics` в Mitra или перетащите его в Mitra с рабочего стола или из файлового менеджера. Перетаскивание работает и в обычной вкладке браузера, ничего устанавливать не нужно. Несколько файлов открываются по очереди.

Mitra спрашивает, в какой календарь добавить записи. Прежде чем что-то добавить, он показывает, что этот календарь не может сохранить: записи, которые будут пропущены, и данные, которые потеряют некоторые записи, например напоминания в календаре, где их нет. Чтобы продолжить, нажмите кнопку с числом добавляемых записей, например **Добавить 12 записей**. Чтобы выбрать другой календарь, вернитесь назад стрелкой. Сам файл не меняется.

Каждая запись добавляется новой копией, поэтому если добавить один и тот же файл дважды, каждая запись появится дважды. Ничего из того, что уже есть в календаре, не перезаписывается.

Подзадачи и зависимости между записями одного файла после импорта остаются связанными. Удалённые повторения серии остаются удалёнными. Серия с изменёнными повторениями, например когда одну встречу перенесли на другой день, пропускается, потому что Mitra не может добавить серию вместе с её изменениями.

Если добавление прервётся на полпути, Mitra удалит уже добавленные записи, чтобы ничего из файла не осталось импортированным наполовину. Если удалить какие-то из них не получится, Mitra сообщит, сколько записей нужно удалить вручную.

## Как подписаться по ссылке webcal

Сайты, на которых можно подписаться на календарь, например на спортивные матчи, школьные четверти или праздничные дни, обычно дают ссылку на адрес `webcal://`. Нажмите на неё, и Mitra откроет форму **Подписка на календарь** с уже заполненным адресом. Проверьте его, при необходимости заполните **Имя пользователя (необязательно)** и **Пароль (необязательно)** и нажмите **Подключить**. Затем включите календарь и нажмите **Сохранить**.

Нажатие на ссылку само по себе никогда не оформляет подписку: Mitra загружает ленту только после того, как вы нажмёте **Подключить**.

Подписка представляет собой один календарь только для чтения, который Mitra обновляет из ленты. Как это работает, описано в разделе [Подписки на календари](integrations/subscriptions.md).
