---
title: Atalhos de teclado
description: "Use o Mitra pelo teclado: vistas, navegação, entradas e a paleta de comandos."
---

Pressione <kbd>?</kbd> em qualquer lugar do calendário para abrir a lista de atalhos. Ela sempre corresponde à versão que você está usando. As teclas seguem as convenções de calendários web como Google Calendar, Notion Calendar e Proton Calendar, então o que você já sabe vale aqui também.

## Vistas

| Ação | Teclas |
| --- | --- |
| Vista de semana | <kbd>W</kbd> |
| Vista de mês | <kbd>M</kbd> |
| Vista de ano | <kbd>Y</kbd> |
| Vista de linha do tempo | <kbd>L</kbd> |
| Vista de tabela | <kbd>S</kbd> |

## Navegação

| Ação | Teclas |
| --- | --- |
| Ir para hoje | <kbd>T</kbd> |
| Avançar uma semana / mês / ano | <kbd>→</kbd> |
| Voltar uma semana / mês / ano | <kbd>←</kbd> |
| Ir para uma data específica | <kbd>G</kbd> |

## Entradas

| Ação | Teclas |
| --- | --- |
| Criar uma entrada | <kbd>C</kbd> |
| Excluir a entrada aberta | <kbd>Delete</kbd> ou <kbd>Backspace</kbd> |
| Excluir apenas esta entrada de uma série | <kbd>Ctrl</kbd> <kbd>Delete</kbd> |
| Mover ou redimensionar apenas esta entrada de uma série | segure <kbd>Ctrl</kbd> ao soltar |
| Duplicar uma entrada | segure <kbd>Alt</kbd> ao soltar |
| Escolher um status de tarefa | <kbd>Alt</kbd> + clique na caixa de seleção, ou clique com o botão direito nela |
| Zoom na vista | <kbd>Ctrl</kbd> + rolar |

## Geral

| Ação | Teclas |
| --- | --- |
| Pesquisar entradas ou executar um comando | <kbd>/</kbd> ou <kbd>Ctrl</kbd> <kbd>P</kbd> ou <kbd>Ctrl</kbd> <kbd>K</kbd> |
| Atalhos de teclado | <kbd>?</kbd> |
| [Configurações](settings.md) | <kbd>Ctrl</kbd> <kbd>,</kbd> |
| [Mostrar apenas um calendário](calendars.md#show-only-one-calendar), ou trazer os outros de volta | <kbd>Alt</kbd> + clique no olho dele na barra lateral |
| Fechar ou voltar | <kbd>Esc</kbd> |

> [!NOTE]
> Em um Mac, <kbd>Ctrl</kbd> vale como <kbd>⌘</kbd> e <kbd>Alt</kbd> como <kbd>⌥</kbd> em todo o texto, e <kbd>⌫</kbd> faz as vezes de <kbd>Delete</kbd> (<kbd>Backspace</kbd> também exclui em todo lugar).

Os atalhos de uma única letra nunca disparam enquanto você digita em um campo de texto.

## Paleta de comandos

Pressione <kbd>/</kbd>, <kbd>Ctrl</kbd> + <kbd>K</kbd> ou <kbd>Ctrl</kbd> + <kbd>P</kbd> para pesquisar suas entradas ou executar um comando; os três fazem a mesma coisa. A pesquisa percorre os títulos, as descrições e os locais de todos os seus calendários, não só os dias na tela, e lista uma entrada recorrente uma só vez. Escolher uma entrada vai até a data dela e a abre. Os comandos cobrem as vistas, a navegação, as novas entradas, seus calendários e suas configurações, e cada um mostra suas teclas ao lado, para você aprendê-las pelo caminho.
