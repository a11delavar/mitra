在日历中任何地方按 <kbd>?</kbd>，都能打开快捷键列表。列表始终与你正在使用的版本保持一致。这些按键沿用了 Google 日历、Notion Calendar、Proton Calendar 等网页日历的惯例，你已经熟悉的操作在这里照样适用。

## 视图

| 操作 | 按键 |
| --- | --- |
| 周视图 | <kbd>W</kbd> |
| 月视图 | <kbd>M</kbd> |
| 年视图 | <kbd>Y</kbd> |
| 时间线视图 | <kbd>L</kbd> |
| 表格视图 | <kbd>S</kbd> |

## 导航

| 操作 | 按键 |
| --- | --- |
| 回到今天 | <kbd>T</kbd> |
| 前进一周 / 一个月 / 一年 | <kbd>→</kbd> |
| 后退一周 / 一个月 / 一年 | <kbd>←</kbd> |
| 跳转到指定日期 | <kbd>G</kbd> |

## 条目

| 操作 | 按键 |
| --- | --- |
| 新建条目 | <kbd>C</kbd> |
| 删除已打开的条目 | <kbd>Delete</kbd> 或 <kbd>Backspace</kbd> |
| 只删除重复条目中的这一次 | <kbd>Ctrl</kbd> <kbd>Delete</kbd> |
| 只移动或调整重复条目中的这一次 | 放下时按住 <kbd>Ctrl</kbd> |
| 创建条目副本 | 放下时按住 <kbd>Alt</kbd> |
| 选择任务状态 | <kbd>Alt</kbd> + 点击复选框，或右键点击复选框 |
| 缩放视图 | <kbd>Ctrl</kbd> + 滚动 |

## 常规

| 操作 | 按键 |
| --- | --- |
| 搜索条目或运行命令 | <kbd>/</kbd> 或 <kbd>Ctrl</kbd> <kbd>P</kbd> 或 <kbd>Ctrl</kbd> <kbd>K</kbd> |
| 键盘快捷键 | <kbd>?</kbd> |
| [设置](settings.md) | <kbd>Ctrl</kbd> <kbd>,</kbd> |
| [只显示一个日历](calendars.md#show-only-one-calendar)，或恢复其他日历 | <kbd>Alt</kbd> + 点击侧边栏中该日历的眼睛图标 |
| 关闭或返回 | <kbd>Esc</kbd> |

> [!NOTE]
> 在 Mac 上，文中所有的 <kbd>Ctrl</kbd> 都对应 <kbd>⌘</kbd>，<kbd>Alt</kbd> 对应 <kbd>⌥</kbd>，而 <kbd>Delete</kbd> 对应 <kbd>⌫</kbd>（在任何平台上，<kbd>Backspace</kbd> 也都能删除）。

在文本框中输入时，单字母快捷键不会触发。

## 命令面板

按 <kbd>/</kbd>、<kbd>Ctrl</kbd> + <kbd>K</kbd> 或 <kbd>Ctrl</kbd> + <kbd>P</kbd>，即可搜索条目或运行命令，三者的效果完全相同。搜索范围涵盖所有日历中条目的标题、描述和地点，而不仅限于屏幕上显示的日期；重复条目只会列出一次。隐藏日历中的条目以淡色显示。选择一个条目，就会跳转到它所在的日期并将其打开；如果它的日历被隐藏，会重新显示该日历。命令涵盖视图切换、导航、新建条目、日历管理和设置，每条命令旁边都标有对应的快捷键，用着用着就记住了。
