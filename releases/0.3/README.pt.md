title: Lembretes, uma paleta de comandos, vários usuários

Esta versão lembra você antes das coisas começarem, deixa cada ação a um toque de tecla e permite que uma família ou uma equipe divida um só Mitra, cada pessoa com seus próprios calendários. É também a primeira que pode aprender qualquer idioma.

## Lembretes
O Mitra lembra você antes de uma entrada começar, no celular ou no computador, com uma notificação push. As entradas novas vêm com um lembrete meia hora antes, que você pode alterar ou remover.

## Paleta de comandos
Pressione Ctrl+P, ou ⌘P no Mac, e digite: um comando, uma data para ir até ela ou o título de uma entrada para abri-la.

<picture>
	<source media="(prefers-color-scheme: dark)" srcset="palette-dark.webp">
	<img src="palette-light.webp" alt="A paleta de comandos">
</picture>

Documentação: [Atalhos](../../docs/shortcuts.md)

## Internacionalização
Cada palavra do Mitra agora pode ser traduzida, e uma troca de idioma vale na hora, sem recarregar. O alemão é o primeiro idioma além do inglês.
