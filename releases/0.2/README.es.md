Esta versión trae entradas que se repiten y permite mover una entrada de un calendario a otro.

## Entradas que se repiten
Una entrada puede repetirse cada día, semana, mes o año, o según una regla propia: cada dos semanas en lunes y jueves, o el último viernes de cada mes. Puede terminar tras un número de veces o en una fecha, y una repetición concreta se puede omitir. Cambia una repetición y Mitra te pregunta si te refieres solo a esa, a esa y a las siguientes, o a todas. Las reglas viajan con tu calendario CalDAV en ambos sentidos, así que los calendarios que ya usas se repiten igual.
