这个版本带来了可以重复的条目，还能把条目从一个日历移到另一个日历。

## 重复条目
条目可以每天、每周、每月或每年重复，也可以按你自己定的规则重复：比如每两周的周一和周四，或者每月的最后一个周五。重复可以在发生一定次数后结束，也可以在某个日期结束，其中某一次还可以单独跳过。修改其中一次时，Mitra 会问你要改的是此条目、此条目及后续条目，还是所有条目。重复规则会随 CalDAV 日历双向同步，你正在用的其他日历也会按同样的规则重复。
